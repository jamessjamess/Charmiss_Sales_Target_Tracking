# บทบาทและสิทธิ์ (`modules/role-management`, id `roleManagement`)

ตั้งค่าระบบ · fit · ผู้แก้ไขตั้งต้น: ผู้ดูแลระบบ (บทบาทอื่นไม่เห็นหน้านี้) · กฎสิทธิ์ดู `business-rules.md` หัวข้อสิทธิ์

## หัวหน้า

- ชื่อหน้า `บทบาทและสิทธิ์` · คำอธิบาย `กำหนดสิทธิ์การเข้าถึงแต่ละหน้าของแต่ละบทบาท และบทบาทของผู้ใช้`
- ปุ่ม: `ประวัติการแก้ไข ▾` (Audit ของสิทธิ์ · บทบาท · ผู้ใช้) · `ส่งออก ▾` (เมทริกซ์ `Roles-Permissions_{YYYYMMDD}`) · แก้ไข / บันทึก / ยกเลิก
- ข้างแท็บมีข้อความข้อจำกัด: สิทธิ์ใน Prototype ทำงานเฉพาะฝั่งหน้าจอ

## แท็บสิทธิ์ตามหน้า (ค่าเริ่มต้น)

- โครงตาราง:
  - แถว = หน้า จัดกลุ่มตามเมนูข้าง (มีเลขขั้นของ Sales Planning) · สิทธิ์ย่อยย่อหน้าเข้า · กลุ่มสุดท้าย `ทุกหน้า` (ส่งออก)
  - คอลัมน์ = บทบาทตามลำดับในแท็บบทบาท
  - หัวตารางและคอลัมน์แรกติด
- ช่อง = Chip `ไม่เห็น` · `ดู` · `แก้ไข` · `แก้ไข · ทีม` · `✓` / `–` (ปุ่มเฉพาะ) · จุดมุม = ต่างจากค่าตั้งต้น
- ตัวกรอง Module · บทบาท (หลายค่า) · `เฉพาะที่ต่างจากค่าตั้งต้น` + Legend
- เมนูหัวคอลัมน์:
  - (แก้ไข) ตั้งทั้งคอลัมน์ · คืนค่าตั้งต้นของบทบาท
  - `ดูตัวอย่างในมุมมองนี้` (ทุกโหมด) = ตั้งมุมมองผู้ใช้เป็นผู้ใช้คนแรกของบทบาท แล้วไปหน้าแรกที่เห็น
- โหมดแก้ไข:
  - คลิกช่อง = เมนูระดับ (+ ทุก Channel / เฉพาะทีม เมื่อรายการนั้นกำหนดขอบเขตได้)
  - ⋯ ของกลุ่ม = ตั้งทั้ง Module เฉพาะบทบาทที่แสดง · `คืนค่าตั้งต้นทั้งตาราง`
  - หลังทุกการแก้ใช้กฎสิทธิ์ย่อยและแจ้ง `ปรับสิทธิ์ย่อยให้ไม่สูงกว่าหน้าหลัก: …`

## แท็บบทบาท

- คอลัมน์: ลำดับ · ชื่อ · คำอธิบาย · จำนวนผู้ใช้ · ประเภท (ตั้งต้น / สร้างเอง)
- โหมดแก้ไข:
  - `+ เพิ่มบทบาท`: ชื่อ (ห้ามว่าง ห้ามซ้ำ) · คำอธิบาย · คัดลอกสิทธิ์จาก… (ไม่คัดลอก = ดูทุกหน้า)
  - แก้ชื่อและคำอธิบายในแถว
  - ลบได้เฉพาะบทบาทที่สร้างเองและไม่มีผู้ใช้ (ไม่อย่างนั้นปุ่มกดไม่ได้พร้อมเหตุผล)
  - ลาก ⋮⋮ หรือกด ↑ ↓ จัดลำดับ (= ลำดับคอลัมน์และกลุ่มในตัวเลือกมุมมองผู้ใช้)

## แท็บผู้ใช้

- คอลัมน์: ชื่อ · บทบาท (Chip) · ทีมขาย (`{Channel} · {บทบาทในทีม}` ณ เดือนปัจจุบันจำลอง) · สถานะ
- ตัวกรอง: ค้นหาชื่อ · บทบาท · Channel ของทีม · สถานะ
- โหมดแก้ไข:
  - เลือกบทบาทได้หลายค่า · เปิด / ปิดใช้งาน
  - `+ เพิ่มผู้ใช้` จาก Sales Person Master (ที่ทำงานอยู่และยังไม่เป็นผู้ใช้) หรือผู้ใช้ที่ไม่ใช่ฝ่ายขาย · ต้องมีอย่างน้อย 1 บทบาท
- คลิกชื่อ = Drawer สิทธิ์ที่มีผลจริงทุกรายการ + บทบาทที่ให้สิทธิ์นั้น

## บันทึก

1. ต้องมีผู้ใช้ที่เปิดใช้งานและแก้หน้านี้ได้อย่างน้อย 1 คน ไม่อย่างนั้นขึ้น `บันทึกไม่ได้`
2. กล่องสรุป `เปลี่ยน {n} ช่อง ใน {m} บทบาท · กระทบผู้ใช้ {k} คน` (+ แก้ข้อมูลบทบาท n รายการ)
3. ถ้าเอาสิทธิ์แก้หน้านี้ออกจากตัวเอง ต้องยืนยันอีกครั้ง (danger)
4. บันทึก `master.roles` · `master.permissions` · `master.users` + Audit log แล้วโหลดหน้าใหม่
   (เมนู ตัวเลือกมุมมองผู้ใช้ และปุ่มทุกหน้าเปลี่ยนตามสิทธิ์ใหม่)
