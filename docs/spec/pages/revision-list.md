# แท็บ Revision ของ Plan Summary (เดิม Revision List · `modules/summary/summary-revision.js` revisionTab)

> CR-39: ย้ายมาเป็นแท็บ `Revision` ของ Plan Summary (`#revision`) · `modules/revision-list` เหลือเป็นทางผ่าน · สิทธิ์ `revisionList` เป็นสิทธิ์ส่วนของหน้า Plan Summary ·
> ปีแผน = ปีของตัวเลือก Revision ที่หัวหน้า Plan Summary (ไม่มี yearPicker) · Flag `approval` เปิด = ปุ่ม `ส่งขออนุมัติ` / ลิงก์ `ดูคำขออนุมัติ` แทน เสนอ Lock / Lock / ส่งกลับ (ส่วน CR-39 ท้ายไฟล์)

CR-38 · กลุ่มเมนู `REVISION` ต่อจาก Sales Planning · ไอคอน `V` · Flag `revision` (ปิด = ไม่อยู่ในเมนู ไม่มีแถวในเมทริกซ์สิทธิ์ · registry `feature`) · กฎทั้งหมดที่ [revision.md](../revision.md)
สิทธิ์หน้า `revisionList` (ทุกบทบาท = ดู · Management · MD · ผู้ดูแลระบบ = แก้ไข) + สิทธิ์ย่อยแบบปุ่ม `revision.open` · `revision.submit` (Management) · `revision.lock` (MD) — ผู้ดูแลระบบไม่มีสิทธิ์ย่อยทั้ง 3 (D-152)

- หัวหน้า: `Revision List` · `?` · ตัวเลือกปีแผน (`components.yearPicker` · `app.planYear`) · `ส่งออก ▾` · ปุ่มคำสั่งตามสิทธิ์และสถานะ (ไม่มีปุ่มคำสั่ง = ข้อความ `ดูอย่างเดียว` ·
  MD ระหว่างรอบร่าง = `{ชื่อรอบ} ยังเป็นร่าง · Lock ได้เมื่อ Management เสนอ Lock` · ไม่มีรอบเปิดและไม่มีสิทธิ์เปิด = `เปิดรอบใหม่ได้เมื่อรอบล่าสุด Lock แล้ว`)

## การ์ดสถานะรอบปัจจุบัน (`components.revisionCard` · ใช้ร่วมกับแท็บติดตามสถานะของ Plan Summary)

- รอบปัจจุบัน = รอบร่าง / รอ Lock ของปี → รอบ Lock ล่าสุด
- บรรทัด 1: ชื่อรอบ · ป้ายสถานะ (`components.revisionBadge`: ร่าง เทา · รอ Lock เหลือง · Lock แล้ว เขียว) · `มีผลตั้งแต่ {เดือน}`
- บรรทัด 2: `เปิดโดย {ผู้ทำ} เมื่อ {วันที่} · เหตุผล: {ข้อความ}` · MD ส่งกลับ = ข้อความของ MD สีเหลืองจนกว่าจะเสนอใหม่
- บรรทัด 3: `Total Target X บาท ({รอบก่อน} Y · ±ส่วนต่าง · ±%)` (`revision.overview`)
- บรรทัด 4: `ตรวจก่อนเสนอ Lock:` Chip `ครบ` / `ขาด` ของ 3 ข้อบังคับ + `แผน SKU ครบเป้า` (คำเตือน `ขาด N หน่วยขาย`) · กด Chip = ไปหน้าที่ต้องแก้ · รอบ Lock = ผลตรวจที่เก็บใน Snapshot

## ปุ่มคำสั่ง (Dialog `components.dialog`)

| สถานะรอบล่าสุด | ปุ่ม | สิทธิ์ | Dialog |
|---|---|---|---|
| ไม่มีรอบเปิดอยู่ | `เปิด Revision ใหม่` | `revision.open` | ชื่อรอบ (ระบบตั้ง) · เดือนที่มีผล (เฉพาะเดือนที่ใช้ได้ · ค่าเริ่มต้นเดือนถัดไป · R1 = เดือนแรกของปี ไม่มีตัวเลือก) · หมายเหตุการคัดลอกจากรอบก่อน · เหตุผล (บังคับ) |
| ร่าง | `เสนอ Lock` | `revision.submit` | สรุปการเปลี่ยนแปลงเทียบรอบก่อน (Total + ทุก Channel `a → b บาท (±)`) · คำเตือนแผน SKU · ข้อความถึง MD · ข้อบังคับไม่ครบ = แจ้งรายการที่ขาดแล้วไม่เปลี่ยนสถานะ |
| รอ Lock | `ถอนการเสนอ` | `revision.submit` | ยืนยัน → ร่าง |
| รอ Lock | `ส่งกลับแก้ไข` | `revision.lock` | ข้อความถึง Management (บังคับ) → ร่าง |
| รอ Lock | `Lock` | `revision.lock` | ชั้น 1: `เมื่อ Lock แล้วจะแก้ไขไม่ได้` + คำอธิบาย Snapshot → `ดำเนินการต่อ` · ชั้น 2: พิมพ์ชื่อรอบ (ตรงเท่านั้น) → Lock |

- สำเร็จ = Toast `เปิด / เสนอ Lock / ถอนการเสนอ / Lock / ส่งกลับ {ชื่อรอบ} แล้ว` · ไม่สำเร็จ = ข้อความจาก `labels.revision.errors` · ไม่มีปุ่มลบรอบหรือปลด Lock

## ตาราง Revision ของปี

- คอลัมน์: Revision · สถานะ (ป้าย) · มีผลตั้งแต่ · Total Target (บาท) · เปลี่ยนจากรอบก่อน (บาท · % · R1 = `–`) · เหตุผล (ตัดด้วย `…` Tooltip เต็ม) · Lock โดย / เมื่อ · จัดการ
- จัดการ: `ดู` (เลือกรอบ `ui.revision` แล้วเปิด Annual Target) · `เปรียบเทียบกับรอบก่อน` (`ui.revisionCompare = { a: รอบก่อน, b: รอบนี้ }` → Revision Compare · R1 = ใช้ไม่ได้) ·
  `ส่งออก ▾` (เป้าหมายและแผนของรอบ: Channel · หน่วยขาย · เป้าหมายทั้งปี · แผน SKU Net Sales · เป้าหมายรายเดือน)
- คลิกแถว = กาง / ซ่อน `ประวัติ` (ไทม์ไลน์ เปิด → เสนอ → ส่งกลับ → เสนอ → Lock: การกระทำ · ผู้ทำ · เวลา · ข้อความ)
- ส่งออกหน้า (`ส่งออก ▾` ที่หัวหน้า) = ตาราง Revision ของปีที่เลือก

## CR-39 (แท็บของ Plan Summary)

- แถวปุ่มบนสุดของแท็บ: ปุ่มคำสั่ง (ซ้าย) · `ส่งออก ▾` (ขวา) · สูงเท่าจอ ตารางเลื่อนภายในการ์ด (หน้าไม่เลื่อนที่ 1920×1080)
- `เปิด Revision ใหม่` (Management · ไม่มีรอบเปิดอยู่ในปีที่เลือก): Dialog มีตัวเลือก `ปีแผน` เมื่อมีหลายปีที่ยังไม่มีรอบเปิดอยู่ (เปิด R1 ของปีอื่นได้) · อื่นตาม CR-38
- Flag `approval` เปิด: ร่าง = `ส่งขออนุมัติ` (Management · Dialog: ชุดสรุปแบบย่อ Total และ Channel เทียบรอบก่อน · คำเตือนแผน SKU · ขั้นอนุมัติที่จะผ่านตามตั้งค่า ·
  ข้อความถึงผู้อนุมัติ บังคับ · 3 ข้อบังคับไม่ครบ = ส่งไม่ได้) · รออนุมัติ / Lock แล้ว = ลิงก์ `ดูคำขออนุมัติ` (หน้า Approval `#request=<id>`) · ไม่มีปุ่ม Lock / ส่งกลับในแท็บนี้
- การ์ดสถานะ: `ตรวจก่อนส่งขออนุมัติ:` · บรรทัด `ส่งขออนุมัติโดย …` · ส่งกลับ = `ส่งกลับแก้ไข: {ข้อความ}` จนกว่าจะส่งใหม่
- แถวตาราง: ปุ่ม `ดู` · `เปรียบเทียบกับรอบก่อน` · `ส่งออก ▾` รูปแบบเดียวกัน (btn-secondary) ชิดขวาเท่ากันทุกแถว · รอบแรกของปี = เปรียบเทียบสีเทาใช้ไม่ได้ + Tooltip `ยังไม่มีรอบก่อนหน้า` ·
  เปรียบเทียบกับรอบก่อน = ไปแท็บเปรียบเทียบ (A = รอบก่อน · B = รอบนี้)
- ประวัติไม่ว่าง: R1 รายการแรก `สร้างจากข้อมูลตั้งต้น · {วันที่}` · รอบอื่นเริ่มด้วย `เปิดรอบ`
- สำเร็จ = Toast แล้วโหลดหน้าใหม่ (ตัวเลือก Revision และป้ายของรอบที่หัวหน้าเปลี่ยนตามรอบ · CR-40 ไม่มีแถบสถานะ)
