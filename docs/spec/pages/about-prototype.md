# เกี่ยวกับ Prototype (`modules/about-prototype`, id `aboutPrototype`)

ข้อมูลโครงการ · fit · ลิงก์เล็กที่ Header · ข้อความทั้งหมดจาก `pages.aboutPrototype`

- แท็บ:
  - ขอบเขต (+ สิ่งที่ตัดออก + ข้อจำกัด: สิทธิ์ทำงานเฉพาะฝั่งหน้าจอ)
  - Decision log (`decisions`)
  - คำถามที่ค้าง (`openQuestions` · ลิงก์ `about-prototype/index.html#open-questions` เปิดแท็บนี้)
  - ขั้นต่อไป
- ท้ายหน้ามีกล่อง "สิ่งที่ขออนุมัติ" (`page.approve`) ที่ layout ต่อให้
- เนื้อหาแท็บเลื่อนภายในการ์ด · ตอนพิมพ์แสดงทุกแท็บต่อกัน
- รายการที่ผูก Flag (`feature` / `!feature`) ซ่อนหรือแสดงตาม Phase
- เมื่อตกลงข้อสรุปใหม่ ให้อัปเดต Decision log และคำถามที่ค้างให้ตรงกับ `docs/DECISIONS.md` และ `docs/spec/open-items.md`
