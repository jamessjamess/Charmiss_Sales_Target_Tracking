# ขั้นที่ 4 Plan Summary (`modules/summary`, id `summary`)

Sales Planning ขั้นที่ 4 (เลขขั้นแสดงเฉพาะในเมนูข้าง · CR-27 ไม่มี `ขั้นที่ x/4` ในหัวข้อหน้า) · อิงปีแผน · หน้าเดียวที่เลื่อนแนวตั้งได้ · ข้อมูลทั้งหมดมาจาก `core/report.js` (ใช้ร่วมกับตัวนับในเมนูข้าง)

## แท็บ

- `รายงานสรุปแผน` | `ติดตามสถานะ (n)` → เปิดแท็บรายงานเป็นค่าเริ่มต้นเสมอ · จำแท็บล่าสุดที่ `ui.summaryTab`
- `n` = จำนวนหน่วยขายที่มีประเด็น (ตัวเดียวกับตัวเลขในเมนูข้าง · 0 = ไม่แสดงวงเล็บ)
  - Phase 1 = หน่วยขายที่แผนมีส่วนต่าง (ขาดหรือเกินเกิน ±1 บาท) หรือไม่มีผู้รับผิดชอบ
  - ข้อมูลตั้งต้นมี 9 หน่วยขาย

## ติดตามสถานะ (พิมพ์ไม่ได้ · ตอนพิมพ์เหลือข้อความแจ้ง)

- หัวข้อ `รายการที่ต้องดำเนินการรายหน่วยขาย` · ข้อความรอง `ยังจัดสรรไม่ครบ {x} จาก {y} หน่วยขาย` (x = สถานะไม่ใช่จัดสรรครบ · ข้อมูลตั้งต้น 9 จาก 10)
- ตารางเดียว 1 แถวต่อหน่วยขาย:
  - Channel (แถบสี) · หน่วยขาย (ลิงก์ไปหน้าวางแผน SKU) · ผู้รับผิดชอบ (`ยังไม่มีผู้รับผิดชอบ` สีแดง)
  - CR-28 ส่วนต่าง = `ขาด 2.70 ล้าน (24.7%)` (% = |ส่วนต่าง| ÷ เป้าหมายของหน่วยขาย · `calc.gapPct`) · จัดสรรครบ / ยังไม่กำหนด = ข้อความอย่างเดียว
  - CR-28 การดำเนินการถัดไป = ปุ่มเล็ก `ไปแก้ไข →` (หน้าของขั้นที่ต้องทำ · ปกติ SKU Planning ของหน่วยนั้น · ตั้ง `ui.selection`) /
    ไม่มีผู้รับผิดชอบ = `กำหนดผู้รับผิดชอบ →` (หน้าผู้รับผิดชอบ) · ไม่มีประเด็น = `–` · Tooltip บอกหน้าและการดำเนินการ
- เรียง (CR-28): ไม่มีผู้รับผิดชอบ → % ส่วนต่างมากไปน้อย (`planActions` `sort: 'pct'`) → ไม่มีประเด็น (ท้ายตาราง สีจาง)
- ตัวกรอง Channel · ผู้รับผิดชอบ + CR-28 แท็บ `ทั้งหมด (n) · ขาด (n) · เกิน (n) · จัดสรรครบ (n) · ไม่มีผู้รับผิดชอบ (n)` แถวเดียวกัน
  (`calc.actionTabs` นับหลังตัวกรอง Channel / ผู้รับผิดชอบ · ไม่มีผู้รับผิดชอบนับซ้อนกับสถานะส่วนต่างได้ · 0 = สีจางแต่ยังกดได้ · จำที่ `ui.statusFilter`) —
  แทน Checkbox `เฉพาะที่มีส่วนต่าง` และสวิตช์ `แสดงเฉพาะที่มีประเด็น` · ข้อมูลตั้งต้น ทั้งหมด 10 · ขาด 7 · เกิน 2 · จัดสรรครบ 1 · ไม่มีผู้รับผิดชอบ 0
- ทุกหน่วยจัดสรรครบ = ข้อความ `ทุกหน่วยขายจัดสรรครบแล้ว` พร้อมไอคอนเขียวเหนือตาราง
- **[Phase 2]**:
  - บรรทัดสรุป `Annual Target: …` / `Baseline: …` + `รายงานที่เคยล็อก`
  - ปุ่ม `ล็อก Baseline {ปี}` / `ปลดล็อก Baseline` (Director + เหตุผล)
  - หัวตาราง 2 ชั้น เป้าหมายรายเดือน / แผน SKU (สถานะ · ผู้อนุมัติ · วันที่อนุมัติ · กดสถานะ = Popover ประวัติ)
  - บรรทัด `ร้านค้าย้ายเขตหลังอนุมัติเป้าหมาย: {n} ร้าน · ยอดอ้างอิง {x} บาท` + รายการร้าน (≤ 8)

## รายงานสรุปแผน (พิมพ์ / บันทึก PDF ได้เฉพาะแท็บนี้)

- หัวรายงาน:
  - `รายงานสรุปแผน {ปี}` · `ฉบับที่ {ปี}-DRAFT` + ลายน้ำเฉียง `ฉบับร่าง · ยังไม่ได้รับอนุมัติ` ทุกหน้า
  - `พิมพ์เมื่อ` แสดงเฉพาะตอนพิมพ์
  - **[Phase 2]** ล็อกแล้ว = `{ปี}-BL-{nn}` · สถานะ · เวลาที่ล็อก · ตัวเลขทั้งหมดจาก Snapshot
- เนื้อหา (CR-27 เรียงตามนี้ · Filter Channel อยู่เหนือ KPI):
  1. KPI 4 ใบ (บาทเต็ม) · ใบ Total Target บอก `การเติบโตเทียบ L12M` (CR-24) · ใบที่ 4 = `หน่วยขายที่จัดสรรครบ x / y` (ตั้งต้น 1 / 10)
  2. การ์ดคู่ 55 : 45 สูงเท่ากัน (จอ < 1280px เรียงลง): `ที่มาของการเติบโต` (Waterfall เริ่มจาก `ยอดขาย L12M`) |
     `สัดส่วน Channel L12M เทียบเป้าหมายปี {ปี}` (แท่งซ้อน 100% แถว `L12M` · `{ปี}`)
  3. ตาราง `เป้าหมายและแผนราย Channel และหน่วยขาย` (ขึ้นหน้าใหม่ตอนพิมพ์) — รายละเอียดด้านล่าง
  4. กราฟ `เป้าหมายเทียบแผน รายเดือน` เต็มความกว้าง · เส้นประรายเดือน = ยอดขายอ้างอิง (Legend `ยอดขายอ้างอิง` · ป้ายท้ายเส้น `อ้างอิง`)
  5. `สัดส่วนแผนตามกลุ่มสินค้า` (ขึ้นหน้าใหม่ตอนพิมพ์):
     - `ตาม Status` = แท่งซ้อน 100% แท่งเดียว (ป้ายในช่วง `{ล้านบาท} · {%}` · ช่วงแคบกว่า 10% ดูใน Tooltip) · Legend แสดง Active · New · Clearance เสมอ
       (Status ที่ไม่มีแผน = `New · 0%`) · อยู่เหนือกราฟกลุ่มสินค้า
     - `ตามกลุ่มสินค้า` Series / Category (Top 8) เต็มความกว้างการ์ด
  6. `แผนตามสินค้าและช่องทาง` (Pivot · ต่อจากกลุ่มสินค้าในหน้าเดียวกันตอนพิมพ์) — รายละเอียดด้านล่าง
  7. `เป้าหมายรายผู้รับผิดชอบ` (ขึ้นหน้าใหม่ตอนพิมพ์) — รายละเอียดด้านล่าง
  - **[Phase 2]** การอนุมัติ + ช่องลงนาม Sales Director / Management ต่อท้าย
- ตาราง Total → Channel (พับได้) → หน่วยขาย:
  - คอลัมน์: `ยอดขาย L12M ⓘ · เป้าหมาย · % ของ Total · เป้าหมายเทียบ L12M · แผน Bottom-up · ส่วนต่าง · ผู้รับผิดชอบ`
  - `% ของ Total` = เป้าหมาย ÷ Total Target เสมอ (7-Eleven 26,496,000 ÷ 120,000,000 = 22.08%)
  - **[Phase 2]** มีคอลัมน์สถานะอนุมัติ 2 ไอคอน (Phasing · แผน SKU: `○ ◐ ● ↩ !`) และแถว Channel = `อนุมัติแล้ว x/y`
- **เป้าหมายรายผู้รับผิดชอบ** (คำนวณเฉพาะเดือนที่แต่ละคนรับผิดชอบ):
  - คอลัมน์ `ผู้รับผิดชอบ · หน่วยขายที่ดูแล · เป้าหมาย · แผน · เป้าหมายเทียบแผน · ส่วนต่าง` · เรียงตามเป้าหมายมากไปน้อย (`calc.targetPlanBars`)
  - CR-29 ต่อท้าย `เป้าหมาย YTD · Actual YTD · % ความสำเร็จ` (ย้ายจากตารางผลงานรายบุคคลของหน้าผู้รับผิดชอบเดิม) ณ เดือนปิดล่าสุด (`SP.core.clock` ส.ค. 2026) ·
    เฉพาะเดือนที่คนนั้นรับผิดชอบ รวมคนที่สิ้นสุดแล้ว (`calc.personYtd` = ตัวเลขเดียวกับ `personPerformance`) · % ต่ำกว่า 100% = สีขาด · ≥ 100% = สีครบ
    - ปีแผนยังไม่เริ่ม (2027) = `–` + Tooltip `ยังไม่มียอดขายจริงของปี 2027` · ตัวเลือกหัวตาราง `ผลงานปีแผน 2027 | ดูผลงานปี 2026`
      (ผู้ใช้เลือก: ปี 2026 แสดงเฉพาะ Actual YTD ม.ค.–ส.ค. จากยอดขายจริงของหน่วย · ไม่มีเป้าหมายปี 2026 ในข้อมูล เป้าหมาย YTD และ % = `–`)
    - ป้ายคนที่ตั้งเดือนสุดท้ายไว้ = `สิ้นสุดการรับผิดชอบ {เดือน}` (แทนลาออก)
  - `เป้าหมายเทียบแผน`: ความยาวแท่ง = เป้าหมาย · ขีดตั้ง = แผน · สีตามสถานะ (ขาด / เกิน / ครบ) · ทุกแถวใช้สเกลจริงเดียวกันเริ่มที่ 0
    (`niceScaleMax` ของเป้าหมายและแผน) + แกนเล็กใต้ชื่อคอลัมน์ · แผน 0 ไม่แสดงป้าย `ใหม่`
- **แผนตามสินค้าและช่องทาง ({หน่วยค่า})** (CR-26):
  - ตัวควบคุมแถวเดียว (จำที่ `ui.summaryPivot`): แถว `Series › SKU` · `Category › Sub Category › SKU` · `Status › SKU` / คอลัมน์ `Channel` · `หน่วยขาย`
    (หัวกลุ่มตาม Channel) · `เดือน` · `ไตรมาส` / ค่า `Net Sales` · `Sale Amount` · `จำนวนชิ้น` / แสดงเป็น `ค่า` · `% ของแถว` · `% ของคอลัมน์` /
    ตัวกรอง Series · Channel · หน่วยขาย · Status · ค้นหา SKU (ไม่เลือก Channel ในตารางนี้ = ใช้ตัวกรอง Channel ของรายงาน)
  - Tree พับได้ (ค่าเริ่มต้นพับที่ระดับแรก) + `กางทั้งหมด / พับทั้งหมด` · คอลัมน์และแถว `รวม` · เงินล้านบาท 2 ตำแหน่ง · ชิ้นเต็ม · 0 = ว่าง
  - สีพื้นไล่ความเข้มสีเดียว (สีหลัก ≤ 45%) เทียบภายในระดับแถวเดียวกัน + Legend · คอลัมน์แรกติดซ้าย หัวตารางและแถวรวมติด · สูงสุด 60% ของจอ
  - คอลัมน์ `หน่วยขาย`: คลิกตัวเลขของ SKU = SKU Planning ของหน่วยนั้นพร้อมค้นหา SKU
  - ตัวเลขจาก `report.pivotPlan` (แผน SKU ทุกหน่วยขาย ชุดเดียวกับ KPI แผน Bottom-up) · ส่งออก ▾ แบบแบน 1 แถวต่อ SKU + คอลัมน์ระดับบน
    (`Plan-by-SKU_{ปี}_{YYYYMMDD}` · % เป็นทศนิยม · หัวไฟล์บอกมุมมองและหน่วยค่า)
  - พิมพ์ตามมุมมองและการพับที่แสดง · บรรทัด `มุมมอง: …` แทนตัวควบคุม · หัวตารางซ้ำทุกหน้า
- ตัวเลขกราฟ ตาราง กลุ่มสินค้า และรายผู้รับผิดชอบ แสดงเป็นล้านบาท 2 ตำแหน่ง
- พิมพ์ A4 แนวนอน:
  - CR-27 ขึ้นหน้าใหม่ก่อน ตาราง Channel · กลุ่มสินค้า · รายผู้รับผิดชอบ → ฉบับร่างข้อมูลตั้งต้น 5 หน้า
    (1 หัวรายงาน KPI การ์ดคู่ · 2 ตาราง · 3 กราฟรายเดือน (ไม่พอที่ใต้ตาราง) · 4 กลุ่มสินค้า + Pivot (ตามการพับ) · 5 รายผู้รับผิดชอบ) ·
    ล็อกแล้ว + การอนุมัติ ช่องลงนาม
  - ไม่พิมพ์ Header · เมนูข้าง · ปุ่มก่อนหน้า/ถัดไป (`.tour-nav`) ไม่มีแถบนำทางลอยทับ
  - หัวตารางซ้ำทุกหน้า · ไม่ตัดแถว · ไม่พิมพ์ ⓘ ปุ่ม และหัวข้อของ layout · ตาราง `table-layout: fixed`
