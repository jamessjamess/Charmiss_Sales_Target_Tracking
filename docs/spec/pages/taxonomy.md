# Product List · แท็บ Product Level (เดิมหน้า Category & Series `modules/taxonomy`, id `taxonomy`)

CR-36 ย้ายเป็นแท็บ `Product Level` ของ [products.md](products.md) (โค้ดเดิมทั้งหมด · `renderLevel` ใน `modules/products/products.js`) · เมนู Product Master เหลือ 3 หน้า ·
หน้าเดิม `modules/taxonomy` = ทางผ่าน (`location.replace` → `products/index.html#level` · registry `visible: false` · `perm: 'productList'`) ·
สิทธิ์ = ส่วนของหน้า Product List key เดิม `taxonomy` (ค่าเดิมคงไว้ · workflowBar ของแท็บ `modules: ['taxonomy']`) · กดจำนวนสินค้า = แท็บสินค้าที่กรองแล้ว (`ui.productFilterHandoff` เดิม)

## โครงหน้า

- แท็บ `หมวดสินค้า` | `Series` | `ตารางไขว้` · จำแท็บและเส้นทางที่เลือกที่ `ui.taxonomySelection` และตัวกรองที่ `ui.taxonomyFilters`
- **มุมมองแบบคอลัมน์**:
  - หมวดสินค้า = Category · Sub Category · Type (ระดับละ ~22%) + แผงรายละเอียด (~34%)
  - Series = Series · Sub Series + แผงรายละเอียด
  - หัวคอลัมน์ `{ระดับ} ({จำนวนที่แสดง})` · แต่ละคอลัมน์เลื่อนภายในตัวเอง · จอแคบกว่า 1280px แผงรายละเอียดเป็น Drawer
- แถว:
  - ชื่อ · จำนวน SKU ชิดขวา · `›` เมื่อมีรายการย่อย
  - เลือกแล้วไฮไลต์ รายการแม่ในเส้นทางไฮไลต์อ่อนกว่า · ปิดใช้งาน = จาง + ป้าย
  - `⚠` = ชื่อซ้ำกับระดับบน · ไม่มี SKU · Type ยังไม่มีเลขนำหน้า Product Code — แสดงเฉพาะรายการที่มีปัญหา (ไม่แสดงซ้ำที่รายการแม่ · CR-30)
  - คีย์บอร์ด ↑↓←→ · F2 เปลี่ยนชื่อ
- แผงรายละเอียด:
  - ชื่อ + บรรทัดรอง `{ระดับ} · อยู่ใน {เส้นทางแม่}` (เช่น `Type · อยู่ใน Face › Base` · ระดับบนสุด = ระดับอย่างเดียว) + คำเตือนใต้ชื่อ (CR-30)
  - Type: `เลขนำหน้า Product Code` (2 หลัก · ห้ามซ้ำกับ Type อื่น · `catalog.prefixError`) + `รหัสถัดไป: 12250` (`catalog.nextCode`) · ยังไม่กำหนด = สร้างสินค้าใน Type นั้นไม่ได้
  - สถานะ · จำนวน SKU (ทั้งหมด + ตามตัวกรอง) · SKU ไม่เกิน 10 รายการ + `ดูทั้งหมดในรายการสินค้า ›`
  - Series มีวันเริ่ม / วันสิ้นสุด (ไม่บังคับ) · เลยวันสิ้นสุดแสดงป้าย `สิ้นสุดแล้ว`

## โหมดแก้ไข

- ไม่เปลี่ยนทุกแถวเป็นช่องกรอก แต่แก้ทีละรายการ
- `+ {ระดับ}` ท้ายคอลัมน์ (ต้องเลือกรายการในคอลัมน์ก่อนหน้า) → แถวว่าง Placeholder `ชื่อ {ระดับ}` · Enter บันทึก · Esc ยกเลิก
- เปลี่ยนชื่อ (ดับเบิลคลิก · F2 · ปุ่มในแผง) · ลาก `⋮⋮` จัดลำดับภายในรายการแม่เดียวกัน · รายการที่ยังไม่บันทึกมีจุดสีท้ายชื่อ

| การดำเนินการ | กฎ |
|---|---|
| เพิ่ม / เปลี่ยนชื่อ | ห้ามว่าง ห้ามซ้ำใต้รายการแม่เดียวกัน (ไม่สนตัวพิมพ์และช่องว่างหัวท้าย) |
| ย้ายไปอยู่ใต้… | ย้ายพร้อมรายการย่อย ปลายทางที่มีชื่อซ้ำเลือกไม่ได้ SKU ได้หมวดระดับบนตามปลายทาง |
| ย้าย SKU ไป… | ปลายทางระดับเดียวกันที่ใช้งานอยู่ ติ๊กเลือก SKU (ค่าเริ่มต้นทั้งหมด) · ระดับย่อยของ SKU = รายการย่อยเดียวของปลายทาง (หลายรายการ = ว่าง + เตือน) |
| รวมกับ… | ย้าย SKU ทั้งหมดไปปลายทาง แล้วปิดใช้งานรายการนี้และรายการย่อย (สรุปก่อนยืนยัน) |
| ปิด / เปิดใช้งาน | ปิดรายการแม่ที่มีรายการย่อย → ถามว่าปิดรายการย่อยด้วยหรือไม่ |
| ลบ | เฉพาะรายการที่ไม่มี SKU และไม่มีรายการย่อย (ไม่อย่างนั้นปุ่มกดไม่ได้ + เหตุผล) |

- ทุกการแก้ที่กระทบ SKU แสดงจำนวน SKU ในกล่องยืนยัน
- เลขนำหน้า Product Code ของ Type แก้ในแผงรายละเอียด (ซ้ำ / ไม่ใช่ตัวเลข 2 หลัก = ข้อความผิดพลาด ไม่รับค่า)
- บันทึก = `master.taxonomy` + `master.products` + Audit log (สินค้าที่ย้ายเลิกเป็น "ระบบกำหนด")

## ตัวกรอง (แถวเดียว · CR-30)

- ค้นหาชื่อทุกระดับทั้งสองมิติ (ผลลัพธ์แสดงพร้อมเส้นทาง)
- `Series` (เฉพาะแท็บหมวดสินค้า) · `หมวดสินค้า` = Category (เฉพาะแท็บ Series) · ตารางไขว้ใช้ทั้งสอง · เลือกหลายค่า
- สถานะ · ข้อมูลที่ต้องตรวจ (ไม่มี SKU · ชื่อซ้ำกับระดับบน · Series สิ้นสุดแล้ว · Type ไม่มีเลขนำหน้า)
- Chip + `ล้างตัวกรอง` · ตัดตัวกรอง Category / Sub Category / Sub Series ที่ซ้ำกับคอลัมน์ (ค่าที่จำไว้ของ Sub Category / Sub Series ถูกล้างตอนเปิดหน้า)
- ตัวกรองข้ามมิติ = นับเฉพาะ SKU ที่ตรง `x / y` และซ่อนรายการที่ได้ 0 (มีสวิตช์ให้แสดง) + หัวคอลัมน์ `เฉพาะ Series: …`

## ตารางไขว้ (อ่านอย่างเดียว)

- แถว = Series (กางเป็น Sub Series) · คอลัมน์ = Category (กางเป็น Sub Category)
- ช่อง = จำนวน SKU ที่มีทั้งสองมิติ สีพื้นเข้มตามจำนวน · มีแถวและคอลัมน์รวม (ข้อมูลตั้งต้นรวม 117 จาก 122 SKU)
- คลิกช่อง → หน้ารายการสินค้าที่กรอง Series และหมวดนั้นแล้ว
