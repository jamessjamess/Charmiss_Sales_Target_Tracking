# ขั้นที่ 3 SKU Planning (`modules/sku-planning`, id `skuPlanning`)

Sales Planning ขั้นที่ 3 · fit · อิงปีแผน · ผู้แก้ไขตั้งต้น: Sales Manager / Officer ของทีม Channel นั้น (Channel ในทีมขึ้นก่อนในตัวเลือก)
CR-24: ค่าตั้งต้นและยอดเทียบ = ยอดอ้างอิงของ SKU (ยอดจริงล่าสุดของแต่ละเดือน) · เมนูข้างไม่พับเอง

## โครงหน้า

- **แถว 1** = แถบบริบท:
  - `Channel | หน่วยขาย ‹ ▾ › | ผู้รับผิดชอบ · GP 40%` (หรือ `Platform Fee 20%` · TT ไม่แสดง · ไม่มีค่า = `ยังไม่ได้กำหนด GP` สีแดง)
  - ต่อด้วย `· เป้าหมายทั้งปี · ยอดขาย L12M ⓘ · การเติบโต`
- **แถว 2** = เครื่องมือ:
  - ค้นหา SKU / ชื่อ
  - จัดกลุ่ม Series | Status | ไม่จัดกลุ่ม + พับ / กางทั้งหมด
  - Series ▾ · เรียง ▾
  - มุมมอง จำนวนชิ้น | Sale Amount | Net Sales · ⓘ
  - ☐ แสดงยอดอ้างอิง · ?
- **แถบแก้ไข** (ต่อท้ายแถว 2):
  - แถบสถานะโหมดแก้ไข · `ปรับทั้งหน่วยขาย ±%` · `ปรับให้ครบตามเป้าหมาย` · `+ สร้าง NPD`
  - เมื่อเลือกแถว: `เลือก n รายการ · ปรับ ±% · ตั้งเท่ายอดอ้างอิง · คืนค่าตั้งต้น · ล้างค่า · ยกเลิกการเลือก`
- ตัวอักษร 14px · แถวเดียวที่ 1920 (เมนูข้างเปิด) · จอเล็กขึ้นบรรทัดที่ 2
- CR-24: เมนูข้างเปิดเป็นค่าเริ่มต้น (เลิกกฎพับเองของ CR-11) ผู้ใช้พับเองได้ จำที่ `ui.sidebarCollapsed`
- ตาราง SKU × 12 เดือน + ทั้งปี (+ L12M · การเติบโต) พอดีความกว้างที่เหลือเมื่อเมนูเปิด (1920: ~1634px):
  - หัวตาราง + แถว `เป้าหมาย Net Sales (จาก Phasing)` ติดบน (เป้าหมายรายเดือนจาก Sub-channel Allocation) · Channel ที่ยังไม่มีหน่วยขาย = ลิงก์ไป Sub-channel Allocation
  - แถวรวมแผน (ชิ้น) · รวมแผน Net Sales · คงเหลือ อยู่ต่อจากแถวสุดท้าย และติดล่างเฉพาะเมื่อแถวล้นกล่อง
  - ความกว้าง: ชื่อ SKU 260px · เดือนอย่างน้อย 90px · ทั้งปี 110px (≥ 1600px) / แสดงยอดอ้างอิง: เพิ่ม L12M 100px · การเติบโต 70px ·
    เดือนอย่างน้อย 84px · ตัวเลขเล็กลง 1 ขั้น (14 → 13px) — 1920 ไม่เลื่อนแนวนอน
  - จอ < 1600px: ชื่อ 236px (แสดงยอดอ้างอิง 212px) · ไม่พอ = เลื่อนแนวนอนภายในตาราง คอลัมน์ชื่อติดซ้าย (หน้าไม่เลื่อนแนวนอน)
  - แถว SKU สูง 48px (จอเตี้ยกว่า 700px = 40px)

## คอลัมน์ชื่อ (~260px ติดซ้าย)

- บรรทัด 1 = ชื่อย่อ (ไม่มี = ชื่อที่ตัด Charmiss ออก และแปลงตัวใหญ่ทั้งหมดเป็น Title Case) + Chip Status เดียว (Clearance > New > Discontinued ระหว่างปี)
- บรรทัด 2 = TR Code · Series (· เดือนเริ่มขายของสินค้าใหม่)
- (แก้ไข) Checkbox และปุ่ม ⋯: คืนค่าตั้งต้น · ตั้งเท่ายอดอ้างอิง · ปรับ ±% · ล้างค่า · นำออกจากแผน (กล่องยืนยัน)
- Tooltip: ชื่อเต็ม · รหัส · หมวดสินค้า · Series · RSP (+ ราคาต่อ Account / ราคา Dealer) · Status ของปีแผน

## กลุ่ม ค้นหา เรียง ยอดอ้างอิง

- จัดกลุ่มค่าเริ่มต้นเป็น Series เมื่อหน่วยขายมีเกิน 20 SKU ไม่อย่างนั้นเป็น Status
  - หัวกลุ่มพับได้ มีผลรวมของกลุ่มตามมุมมอง และ Checkbox เลือกทั้งกลุ่ม
  - กลุ่ม Status: สินค้าที่วางขายแล้ว · Clearance · เลิกขายระหว่างปี · สินค้าใหม่ (New) ปี {ปี}
- ค้นหา TR Code / ชื่อย่อ / ชื่อเต็ม (`n จาก m`) · เรียงยอดทั้งปีมากไปน้อย (ค่าเริ่มต้น) · TR Code · ชื่อ · การเติบโต
  - เรียงจากค่าที่บันทึกแล้ว ลำดับไม่กระโดดระหว่างแก้ไข
- แสดงยอดอ้างอิง (`ui.skuShowLastYear`): บรรทัดเล็กสีจางใต้ตัวเลขทุกช่อง (ยอดอ้างอิงของเดือนนั้น) + คอลัมน์ `L12M` · การเติบโต
  (Tooltip หัว L12M = `ยอดขาย L12M (ก.ย. 2025 – ส.ค. 2026) ของ SKU ในแผน = ผลรวมยอดอ้างอิง 12 เดือน`)
- จุดกลวงมุมล่างขวาของช่อง = ยอดอ้างอิงของเดือนนี้เป็นประมาณการ (SKU ไม่มียอดจริงรายเดือนปี 2025 → ใช้ค่าปี 2026) · Tooltip `ใช้ประมาณการปี 2026 เพราะไม่มียอดจริงเดือนนี้` · มีใน Legend
- แถวข้อความท้ายตาราง: SKU ที่มียอดอ้างอิงแต่ไม่อยู่ในแผน (เลิกขาย · ขาดข้อมูลจำเป็น) พร้อมยอดขาย L12M = ที่มาของส่วนต่าง

## เครื่องมือช่วยกรอก (โหมดแก้ไข · มุมมองจำนวนชิ้น)

| เครื่องมือ | การทำงาน |
|---|---|
| ช่อง `ทั้งปี` | กรอกยอดทั้งปีแล้วกระจายไปเดือนที่แก้ได้ |
| ⋯ ของแถว / เลือกหลายแถว | คืนค่าตั้งต้น · ตั้งเท่ายอดอ้างอิง · ปรับ ±% · ล้างค่า |
| ปิดส่วนต่าง | ปุ่มในป้ายแถวคงเหลือ (ทั้งปี) หรือกดช่องคงเหลือของเดือน → เลือกเดือน + SKU → ตารางก่อน/หลัง → ยืนยัน |
| ปรับทั้งหน่วยขาย ±% | ทุก SKU ที่แก้ได้ของหน่วยขาย |
| ปรับให้ครบตามเป้าหมาย | ทุก SKU ที่มีค่ามากกว่า 0 · ทุกเดือนที่แก้ได้ → ตารางก่อน/หลัง → ยืนยัน |
| คีย์บอร์ดและ Excel | Enter ลง · Tab ขวา · ลูกศร · Shift+ลูกศร / Shift+คลิก / ลาก = เลือกช่วง · Ctrl+C / Ctrl+V · Delete · Ctrl+D · Ctrl+R · Ctrl+Z (ภายในรอบแก้ไข) |
| ▲ / ▼ | มุมล่างซ้ายของช่อง เมื่อต่างจากยอดอ้างอิงของเดือนนั้นเกิน ±50% |

- แถวคงเหลือเมื่อทั้งปีขาด: `ขาด x ล้านบาท · ปรับจำนวน หรือเพิ่ม NPD` (ต่ำกว่า 5,000 บาทแสดงเป็นบาท) + (แก้ไข) `ปรับให้ครบตามเป้าหมาย` · `+ สร้าง NPD`
- คงเหลือรายเดือน: ค่าบวก = ขาด · ค่าลบ = เกิน · ✓ = จัดสรรครบ + บรรทัดเล็ก % ของเป้าหมาย สีช่องตามสถานะของเดือน
- ป้าย P มุมบนซ้ายของช่อง (Promotion **[Phase 2]**) · จุด Override มุมบนขวา · จุดกลวงประมาณการมุมล่างขวา · ▲▼ มุมล่างซ้าย · Hover ไฮไลต์แถวและหัวคอลัมน์เดือน

## เพิ่ม SKU และสร้าง NPD

- `+ เพิ่ม SKU` (หัวคอลัมน์ SKU · แถว NPD) = Drawer:
  - ตัวกรอง: ค้นหา · Series · Category / Sub Category · เดือนเริ่มขาย (ค่าเริ่มต้น ม.ค.)
  - รายการ = Product Master ทั้งหมด (SALE · ขายในปีแผน · ยังไม่อยู่ในแผน) แบ่ง 2 กลุ่ม `Listing แล้วใน {หน่วยขาย}` (แสดงก่อน) · `ยังไม่ได้ Listing`
  - เลือกได้หลายรายการ · ขาดข้อมูลจำเป็นแสดงแต่เลือกไม่ได้ (ยกเว้นสินค้าจาก Sales)
  - สินค้าที่ยังไม่ได้ Listing จะได้ Listing โดย Sales ตอนกดบันทึกแผน (ยกเลิก = ไม่มี Listing)
- `เพิ่มทั้ง Series` (เมื่อเลือก Series) ใช้รายการเดียวกัน
- `+ สร้าง NPD` (สิทธิ์ย่อย สร้าง NPD) = Drawer ฟอร์ม:
  - ช่องกรอก: ชื่อสินค้า (ชั่วคราว) * · Series * (`ยังไม่ระบุ` ได้) · หมวดสินค้า · ราคาขายที่หน่วยขายนี้ (รวม VAT) * · เดือนเริ่มขาย * · หน่วยขายอื่นใน Channel · หมายเหตุ
  - บันทึกลง Product Master ทันที แล้วเพิ่มแถวเข้าแผนร่าง (เดือนก่อนเริ่มขายเป็นล็อก 0)

## มุมมอง ราคา และส่งออก

- แก้ไขได้เฉพาะมุมมองจำนวนชิ้น
  - มุมมองเงินคำนวณจากราคาที่มีผลของเดือน
  - มุมมอง Sale Amount: เป้าหมาย = Net Sales ÷ (1 − GP) × 1.07
- Tooltip รายช่อง: `3,000 ชิ้น × 149.00 บาท (ราคาต่อ Account) = 447,000.00 (Sale Amount รวม VAT)` / `÷ 1.07 × (1 − 40%) = 250,654.21 (Net Sales)`
  - Tooltip ช่องระบบเติมบอก `ค่าตั้งต้น = ยอดจริงล่าสุดของเดือนนี้ (2026)` (เดือนประมาณการ = `ใช้ประมาณการปี 2026 เพราะไม่มียอดจริงเดือนนี้`)
    + `ยอดอ้างอิง ({ปี}) {n} ชิ้น · {การเติบโต}`
- ⓘ วิธีคำนวณ: สูตรตาม Channel · ลำดับราคา · แถบแบ่งเงิน Net Sales / GP / VAT
- แผง ?: Legend เต็ม + กฎ + คีย์ลัด (ไม่มี Legend ในแถวเครื่องมือ)
- ส่งออก ▾ `SKU-Plan_{ปี}_{หน่วยขาย}_{YYYYMMDD}` ตามมุมมองที่แสดง:
  - ต่อท้ายด้วย ราคาขาย (รวม VAT) · ที่มาของราคา · Sale Amount ทั้งปี · GP % / Platform Fee % · Net Sales ทั้งปี
- **[Phase 2]** มีตัวเลือกโหมด (สร้างแผนครั้งแรก | ปรับแผน) · เดือนปัจจุบันจำลอง · Plan Baseline · ป้าย `ราคาเปลี่ยนจาก Baseline n เดือน` · ส่งอนุมัติต่อหน่วย
