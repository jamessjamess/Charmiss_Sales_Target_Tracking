# ขั้นที่ 3 SKU Planning (`modules/sku-planning`, id `skuPlanning`)

Sales Planning ขั้นที่ 3 (เลขขั้นแสดงเฉพาะในเมนูข้าง · CR-27 ไม่มี `ขั้นที่ x/4` ในหัวข้อหน้า) · fit · อิงปีแผน · ผู้แก้ไขตั้งต้น: Sales Manager / Officer ของทีม Channel นั้น (Channel ในทีมขึ้นก่อนในตัวเลือก)
CR-24: ค่าตั้งต้นและยอดเทียบ = ยอดอ้างอิงของ SKU (ยอดจริงล่าสุดของแต่ละเดือน) · เมนูข้างไม่พับเอง
CR-27: ข้อมูลตั้งต้นมียอด SKU รายเดือนปี 2025 แล้ว (สร้างจากยอดหน่วยขาย ดู [business-rules.md](../business-rules.md)) → แผน SKU ตั้งต้นทั้งปีของหน่วยขาย ≈ L12M ·
คงเหลือรายเดือนทิศเดียวกันทุกเดือน (7-Eleven ขาดราว 6% ทุกเดือน) · ไม่มีเดือนประมาณการในข้อมูลตั้งต้น

- ตัวอักษร 13px (CR-27 จาก 14px) · แถวเดียวที่ 1920 (เมนูข้างเปิด · โหมดดูสูง 34px) · จอเล็กขึ้นบรรทัดที่ 2

  - หัวตาราง + แถว `เป้าหมาย Net Sales (จาก Phasing)` ติดบน (เป้าหมายรายเดือนจาก Sub-channel Allocation) · Channel ที่ยังไม่มีหน่วยขาย = ลิงก์ไป Sub-channel Allocation

  - ความกว้าง: ชื่อ SKU 230px (CR-26 จาก 260) · ช่วงเวลาขาย 80px + อายุ 50px = 130px (CR-33 แยก 2 คอลัมน์ · รวมเท่าเดิม) · เดือนอย่างน้อย 90px · ทั้งปี 110px (≥ 1600px) /
    แสดงยอดอ้างอิง: ชื่อ 220px · เพิ่ม L12M 100px · การเติบโต 70px · เดือนอย่างน้อย 83px · ตัวเลขเล็กลง 1 ขั้น (14 → 13px) — 1920 ไม่เลื่อนแนวนอน (ตารางกว้างพอดี 1634px)
  - จอ < 1600px: ชื่อ 210px (แสดงยอดอ้างอิง 196px) · อายุ 116px · ไม่พอ = เลื่อนแนวนอนภายในตาราง คอลัมน์ชื่อและอายุติดซ้าย (หน้าไม่เลื่อนแนวนอน)
  - หัวแถวของแถวที่ไม่ใช่ SKU (เป้าหมาย · หัวกลุ่ม · รวม · คงเหลือ · ผู้รับผิดชอบ) ครอบ 2 คอลัมน์
  - แถว SKU สูง 52px (CR-27 จาก 48 ให้ชื่อ 2 บรรทัด + รหัส · จอเตี้ยกว่า 700px = 40px)

  - CR-30 ป้าย `ยังไม่ยืนยัน Listing` (Listing ของหน่วยนี้ = เสนอขาย) · `เดือนเปิดตัวยังไม่ยืนยัน` (NPD แบบไตรมาส · Tooltip บอกไตรมาส)
  - CR-27 ชื่อยาวขึ้นบรรทัดที่สองได้ (สูงสุด 2 บรรทัด เกินจึงตัด `…` + Tooltip ชื่อเต็ม) แทนการตัดบรรทัดเดียว
- บรรทัด 2 = Product Code · Series (· เดือนเริ่มขายของสินค้าใหม่)
- (แก้ไข) Checkbox และปุ่ม ⋯: คืนค่าตั้งต้น · ตั้งเท่ายอดอ้างอิง · ปรับ ±% · ล้างค่า · นำออกจากแผน (กล่องยืนยัน)
- Tooltip: ชื่อเต็ม · รหัส · หมวดสินค้า · Series · ราคาหลัก (+ Promotion Price) · Status ของปีแผน

## คอลัมน์ ช่วงเวลาขาย | อายุ (CR-33 แยกจาก `ช่วงเวลาขาย · อายุ` ของ CR-27 · ติดซ้ายต่อจากชื่อ SKU · รวม 130px เท่าคอลัมน์เดิม · เดือนไม่แคบลง)

- ค่าจาก `calc.salesAge` (นิยามที่ `business-rules.md` หัวข้ออายุการขาย) · ใช้กับทุกมุมมอง (จำนวนชิ้น / Sale Amount / Net Sales) และทุกแบบจัดกลุ่ม
- `ช่วงเวลาขาย` (80px · Tooltip หัวคอลัมน์ `ข้อมูล ณ 1 ก.ย. 2026 · "ปัจจุบัน" = มียอดขายถึงเดือน ส.ค. 2026 · ไม่มียอด = …`):
  - ยังขายอยู่ (ขายล่าสุด = เดือนปิดล่าสุด · `current`) = `พ.ย. 24 – ปัจจุบัน` · หยุดขายแล้ว = `ม.ค. 26 – พ.ค. 26` + ป้าย `ไม่มียอด 3 ด.` (ส้ม · ≥ `NO_SALE_WARN_MONTHS`)
  - ไม่มียอดจริงในหน่วยขายนี้ = เดือนเริ่มขายใน Listing / แผน + `ยังไม่มียอด` · ยังไม่เริ่มขาย = `เริ่ม {เดือน}` / `–`
- `อายุ` (50px): ป้ายกลุ่มจาก `calc.skuAgeGroup(age, asOfMonth)` ชุดเดียวกับตัวกรอง (`content pages.skuPlanning.age.groups`):
  `≤ 1 ปี` (≤ 12 เดือน) · `1–2 ปี` (13–24) · `> 2 ปี` (> 24) · `ยังไม่เริ่มขาย` (NPD / Planned / ยังไม่มีข้อมูล) · **ตัดป้าย `อายุนาน` (CR-27) และข้อความระยะเวลาในช่อง**
  - Tooltip ป้าย = ระยะเวลาจริง `อายุการขาย 1 ปี 10 ด. · เริ่มขายที่ {หน่วยขาย}: {เดือน} · เริ่มขายใน {Channel}: {เดือน} · ขายล่าสุด: {เดือน} · อายุการขาย {x} เดือน`
- หัวกลุ่มแสดง `· ไม่มียอด {n}` เมื่อมี SKU ในกลุ่มติดป้ายไม่มียอด · แถวที่ไม่ใช่ SKU (เป้าหมาย · หัวกลุ่ม · รวม · คงเหลือ · ผู้รับผิดชอบ) ครอบ 3 คอลัมน์
- ตัวกรอง `อายุ ▾` (`calc.ageMatch` → `skuAgeGroup`): ทั้งหมด · ≤ 1 ปี · 1–2 ปี · > 2 ปี · ยังไม่เริ่มขาย (CR-33 เพิ่ม) + Checkbox แยก `เฉพาะที่ไม่มียอด ≥ 3 เดือน` ใช้ร่วมกันได้ ·
  SKU ที่มีเฉพาะ Listing (ยังไม่มียอด) นับอายุจากเดือนเริ่มขายใน Listing · ไม่เก็บ · ไม่มีรายการ = `ไม่มี SKU ตามตัวกรองอายุ`
- ส่งออก: `ช่วงเวลาขาย` · `อายุ` (ป้ายกลุ่ม) · `เริ่มขาย (Channel)` · `อายุการขาย (เดือน)` · `ไม่มียอด (เดือน)` (แทน `เริ่มขาย (หน่วยขาย)` · `ขายล่าสุด`)
- มาจาก Plan Summary (คลิกช่อง SKU × หน่วยขาย): เปิดหน่วยขายนั้นและค้นหา SKU (`ui.skuSearchHandoff` อ่านครั้งเดียว)

## กลุ่ม ค้นหา เรียง ยอดอ้างอิง

- จัดกลุ่มค่าเริ่มต้นเป็น Series เมื่อหน่วยขายมีเกิน 20 SKU ไม่อย่างนั้นเป็น Status
  - หัวกลุ่มพับได้ มีผลรวมของกลุ่มตามมุมมอง และ Checkbox เลือกทั้งกลุ่ม
  - กลุ่ม Status: สินค้าที่วางขายแล้ว · Clearance · เลิกขายระหว่างปี · สินค้าใหม่ (New) ปี {ปี}
- ค้นหา Product Code / ชื่อย่อ / ชื่อเต็ม (`n จาก m`) · เรียงยอดทั้งปีมากไปน้อย (ค่าเริ่มต้น) · Product Code · ชื่อ · การเติบโต ·
  CR-26 อายุการขายมากไปน้อย · ไม่มียอดนานที่สุด · เริ่มขายล่าสุด (ยังไม่เริ่มขายอยู่บนสุด)
  - เรียงจากค่าที่บันทึกแล้ว ลำดับไม่กระโดดระหว่างแก้ไข
- แสดงยอดอ้างอิง (`ui.skuShowLastYear`): บรรทัดเล็กสีจางใต้ตัวเลขทุกช่อง (ยอดอ้างอิงของเดือนนั้น) + คอลัมน์ `L12M` · การเติบโต
  (Tooltip หัว L12M = `ยอดขาย L12M (ก.ย. 2025 – ส.ค. 2026) ของ SKU ในแผน = ผลรวมยอดอ้างอิง 12 เดือน`)
- CR-27 (แทนจุดกลวงรายช่องของ CR-24): เดือนที่มี SKU ใช้ยอดอ้างอิงประมาณการ (ไม่มียอดจริงปีก่อน → ใช้ค่าปีล่าสุด) แสดงป้ายเดียว `ประมาณการ` ที่หัวคอลัมน์เดือนนั้น
  (Tooltip `{n} SKU ไม่มียอดจริงเดือนนี้ของปีก่อน · ยอดอ้างอิงใช้ประมาณการของปีล่าสุด`) · ข้อมูลตั้งต้นไม่มีเดือนประมาณการ
- แถวข้อความท้ายตาราง: SKU ที่มียอดอ้างอิงแต่ไม่อยู่ในแผน (เลิกขาย · ขาดข้อมูลจำเป็น) พร้อมยอดขาย L12M = ที่มาของส่วนต่าง

## เครื่องมือช่วยกรอก (โหมดแก้ไข · มุมมองจำนวนชิ้น)

| เครื่องมือ | การทำงาน |
|---|---|
| ช่อง `ทั้งปี` | กรอกยอดทั้งปีแล้วกระจายไปเดือนที่แก้ได้ |
| ⋯ ของแถว / เลือกหลายแถว | คืนค่าตั้งต้น · ตั้งเท่ายอดอ้างอิง · ปรับ ±% · ล้างค่า |
| ปิดส่วนต่าง | ปุ่มในป้ายแถวคงเหลือ (ทั้งปี) หรือกดช่องคงเหลือของเดือน → เลือกเดือน + SKU → ตารางก่อน/หลัง → ยืนยัน |
| ปรับทั้งหน่วยขาย ±% | ทุก SKU ที่แก้ได้ของหน่วยขาย |
| ปรับให้ครบตามเป้าหมาย | ทุก SKU ที่มีค่ามากกว่า 0 · ทุกเดือนที่แก้ได้ → ตารางก่อน/หลัง → ยืนยัน |
| คีย์บอร์ดและ Excel | Enter ลง · Tab ขวา · ลูกศร · Shift+ลูกศร / Shift+คลิก / ลาก = เลือกช่วง · Ctrl+C / Ctrl+V · Delete · Ctrl+D · Ctrl+R · Ctrl+Z (ภายในรอบแก้ไข) |
| ▲ / ▼ | มุมล่างซ้ายของช่อง เมื่อต่างจากยอดอ้างอิงของเดือนนั้นเกิน ±50% |

- แถวคงเหลือเมื่อทั้งปีขาด: `ขาด x ล้านบาท · ปรับจำนวน หรือเพิ่ม NPD` (ต่ำกว่า 5,000 บาทแสดงเป็นบาท) + (แก้ไข) `ปรับให้ครบตามเป้าหมาย` · `+ สร้าง NPD`
- คงเหลือรายเดือน: ค่าบวก = ขาด · ค่าลบ = เกิน · ✓ = จัดสรรครบ + บรรทัดเล็ก % ของเป้าหมาย สีช่องตามสถานะของเดือน
- ป้าย P มุมบนซ้ายของช่อง (Promotion **[Phase 2]**) · จุด Override มุมบนขวา · ▲▼ มุมล่างซ้าย · Hover ไฮไลต์แถวและหัวคอลัมน์เดือน

## เพิ่ม SKU และสร้าง NPD

- `+ เพิ่ม SKU` (หัวคอลัมน์ SKU · แถว NPD) = Drawer:
  - ตัวกรอง: ค้นหา · Series · Category / Sub Category · เดือนเริ่มขาย (ค่าเริ่มต้น ม.ค.)
  - รายการ = Product Master ทั้งหมด (SALE · ขายในปีแผน · ยังไม่อยู่ในแผน) แบ่ง 2 กลุ่ม `Listing แล้วใน {หน่วยขาย}` (แสดงก่อน) · `ยังไม่ได้ Listing`
  - เลือกได้หลายรายการ · ขาดข้อมูลจำเป็นแสดงแต่เลือกไม่ได้ (ยกเว้นสินค้าจาก Sales)
  - สินค้าที่ยังไม่ได้ Listing จะได้ Listing โดย Sales ตอนกดบันทึกแผน (ยกเลิก = ไม่มี Listing)
  - CR-30 Listing สถานะ `เสนอขาย` อยู่กลุ่ม Listing แล้ว (ไม่อยู่ในแผนตั้งต้น) · เพิ่มแล้วมีป้าย `ยังไม่ยืนยัน Listing`
- `เพิ่มทั้ง Series` (เมื่อเลือก Series) ใช้รายการเดียวกัน
- `+ สร้าง NPD` (สิทธิ์ย่อย สร้าง NPD) = Drawer ฟอร์ม:
  - ช่องกรอก: ชื่อสินค้า (ชั่วคราว) * · Series * (`ยังไม่ระบุ` ได้) · หมวดสินค้าถึงระดับ Type * · ราคาขายที่หน่วยขายนี้ (รวม VAT) * · เดือนเริ่มขาย * · หน่วยขายอื่นใน Channel · หมายเหตุ
  - CR-30 ได้ Product Code จากระบบทันที (`calc.createSalesNpd` · Type ไม่มีเลขนำหน้า = สร้างไม่ได้) · `ใน TRCLOUD = ยังไม่เปิด` · แผน NPD ที่มา `จาก Sales` · ราคา = RSP ราคาหลักตั้งแต่เดือนเริ่มขาย
  - บันทึกลง Product Master ทันที แล้วเพิ่มแถวเข้าแผนร่าง (เดือนก่อนเริ่มขายเป็นล็อก 0)

## ช่วง Listing (CR-30)

- แผนตั้งต้นใช้ Listing ที่มีช่วงทับปีแผนและไม่ใช่เสนอขาย (`calc.listedInYear`)
- เดือนนอกช่วง Listing ของหน่วยขายนี้ = ล็อก 0 (`calc.listingOutside`): ก่อน `fromMonth` = `ก่อนเดือนเริ่มวางขายใน Listing` · หลัง `toMonth` ของสินค้าที่ถอด = `ถอดจาก Listing แล้ว`
- NPD แบบไตรมาสใช้ต้นไตรมาสเป็นเดือนเปิดตัวชั่วคราว → เดือนก่อนหน้าล็อกเป็น Planned (22110 `2028-Q2` = ล็อก ม.ค.–มี.ค. 2028)

## มุมมอง ราคา และส่งออก

- แก้ไขได้เฉพาะมุมมองจำนวนชิ้น
