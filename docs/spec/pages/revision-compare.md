## แถบตัวเลือก

`เปรียบเทียบ [A ▾] กับ [B ▾] [สลับ A ⇄ B]  ระดับ [▾]  ตัวชี้วัด [▾]  [ทั้งปี | รายเดือน]  Channel [▾]  (หน่วยขาย [▾])`

- A / B: ทุกรอบทุกปีแผน รวมรอบร่าง (ป้าย `{ชื่อรอบ} · {สถานะ}`) · ค่าเริ่มต้น A = รอบ Lock ล่าสุด · B = รอบปัจจุบัน (ร่าง / รอ Lock) · มีรอบเดียว = เลือก A ได้อย่างเดียว + `ต้องมีอย่างน้อย 2 Revision (เปิดรอบใหม่ได้ที่ Revision List)`
- ระดับ: Total · Channel (ค่าเริ่มต้น) · หน่วยขาย · Series · SKU · SKU ใช้ได้เมื่อเลือก Channel หรือหน่วยขาย (ไม่เลือก = ตัวเลือกปิดและแสดง Series พร้อมหมายเหตุ)
- ตัวชี้วัด: Net Sales (ค่าเริ่มต้น) · Sale Amount · จำนวนชิ้น (เฉพาะ Series / SKU · ระดับอื่นกลับเป็น Net Sales)
- หน่วยขาย แสดงเมื่อเลือก Channel แล้ว · บรรทัดใต้แถบบอกที่มาของตัวเลข (`ระดับ Total · Channel · หน่วยขาย = เป้าหมาย (Net Sales · Sale Amount จาก GP ของหน่วยขาย)` / `ระดับ Series · SKU = แผน SKU`)
- ตัวเลือกล่าสุดเก็บที่ `ui.revisionCompareOpts` · จาก Revision List `เปรียบเทียบกับรอบก่อน` ส่ง `ui.revisionCompare = { a, b }` (อ่านครั้งเดียว)

## กราฟรายเดือน (`charts.compareLines`)

- หัว `รายเดือน · {ตัวชี้วัด} (ล้านบาท | ชิ้น) · ระดับ {ระดับ}` + `เดือนก่อน {เดือน} ของ {รอบที่ใหม่กว่า} เปลี่ยนไม่ได้ (พื้นเทา)`
- ผลรวมของแถวที่แสดง: เส้น A เส้นประเทา · เส้น B สีหลักมีจุด · แถบส่วนต่างบางใต้กราฟ (B − A · เพิ่ม = เขียว · ลด = แดง · สเกลของส่วนต่าง) ·
  เดือนล็อก = พื้นเทาลายเส้น · เส้นประแนวตั้งที่เดือนที่มีผลของรอบที่ใหม่กว่า + ป้าย `มีผล {เดือน}` · แกน Y เริ่ม 0 (`calc.niceAxis`) · Hover = Tooltip A · B · ส่วนต่าง

## ตาราง

- ทั้งปี: ชื่อแถว · `A · {รอบ}` · `B · {รอบ}` · `ส่วนต่าง (B − A)` (บวกเขียว ลบแดง) · `%` (ส่วนต่าง ÷ A) · `แท่งเทียบ` (A เทา · B สีหลัก ซ้อนแนวนอน สเกลจริงเริ่ม 0 ค่าสูงสุดเดียวกันทั้งตาราง)
- รายเดือน: 3 บรรทัดต่อแถว (A · B · ส่วนต่าง) × ม.ค.–ธ.ค. + รวม · หัวคอลัมน์เดือนล็อกมีคำ `ล็อก` · ช่องเดือนล็อกพื้นเทา (ส่วนต่าง = 0)
- แถวรวมท้ายตาราง · เรียงตาม |ส่วนต่าง| มากไปน้อย · ชื่อ Channel / หน่วยขายเป็นลิงก์กางลงระดับถัดไป (Channel → หน่วยขายของ Channel · หน่วยขาย → SKU ของหน่วยขาย)
- ส่งออก (`ส่งออก ▾`) = ตารางตามตัวเลือกปัจจุบัน (มุมมองรายเดือน = คอลัมน์ A / B ต่อเดือน) · ชื่อไฟล์ `Revision-Compare_{A}_vs_{B}_{วันที่}`

## CR-41 B = ยอดจริง

- มุมมองรายเดือน: ตัวเลือก B = `ยอดจริง` (กลุ่ม ยอดจริง ท้ายรายการ) · ระดับ Total / Channel / หน่วยขาย (Series / SKU เลือกไม่ได้) · สลับ A ⇄ B ไม่ได้
- เดือนที่ยังไม่ปิด = `–` (ทั้งแถว B และส่วนต่าง) · ยอดรวมนับเฉพาะเดือนที่ปิดแล้วทั้ง A และ B · กราฟเส้น B เฉพาะเดือนที่ปิดแล้ว · หมายเหตุใต้แถบเครื่องมือ `ยอดจริงถึง <เดือน>` + ข้อความยอดจริงตัวอย่าง
- มี Revision เดียวและมีเดือนที่ปิดแล้วในปีแผน (S2 ก่อนเปิด R2) = เทียบรอบนั้นกับยอดจริงรายเดือนทันที
- Channel / Total = ยอดจริงของทุกหน่วยใน Master ของ Channel (รวมหน่วยนอกแผน · `revision.actualDataset`)
