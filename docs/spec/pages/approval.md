# Approval (`modules/approval` · id `approval`)

CR-39 · กลุ่มเมนู `APPROVAL` ต่อจาก Sales Planning · ไอคอน `✓` · fit · Flag `approval` · กฎทั้งหมดที่ [approval.md](../approval.md) ·
สิทธิ์หน้า `approval` (ทุกบทบาท = ดู · Management · Sales Director · MD · ผู้ดูแลระบบ = แก้ไข = เพิ่มความคิดเห็น) + ปุ่มเฉพาะ `approval.submit` · `approval.sdConfirm` · `approval.mdLock` · `approval.config`

- เมนู: ป้ายตัวเลขสีแดง (รูปแบบเดียวกับ Plan Summary · `layout` approvalCount) = คำขอที่ผู้ใช้ปัจจุบันต้องดำเนินการ (`approval.waitingFor`) · หน้าเริ่มต้นของ MD = Approval
- หัวหน้า: `Approval` · `?` · `ส่งออก ▾` (ตารางคำขอตามตัวกรองของแท็บทั้งหมด) · แท็บ `รอฉันดำเนินการ n | ทั้งหมด n | ตั้งค่า` (CR-40 แท็บขีดเส้นใต้ · ตัวนับเล็กสีเทา · ทั้งหมด = จำนวนคำขอทั้งหมด) (`#mine` · `#all` · `#settings` · `ui.approvalTab` · ตั้งค่า = เฉพาะผู้มี `approval.config`)

## แท็บรอฉันดำเนินการ

- การ์ด 1 ใบต่อคำขอ: ชื่อรอบ + ป้ายสถานะของรอบ + `ขั้นปัจจุบัน: {ชื่อขั้น}` · `ส่งโดย {ผู้ส่ง} · {วันที่}` · ข้อความ · `Total Target X บาท ({รอบก่อน} · ±ส่วนต่าง · ±%)` (รอบแรก = `(รอบแรกของปี)`) ·
  ป้ายรายการตรวจ 3 ข้อบังคับ + แผน SKU · ปุ่ม `เปิดดู`
- ไม่มีรายการ = `ไม่มีคำขอที่รอคุณดำเนินการ`

## แท็บทั้งหมด

- ตัวกรอง ปีแผน · สถานะ · ตาราง: Revision · ประเภท · สถานะ (ป้าย รอดำเนินการ / อนุมัติแล้ว / ส่งกลับแก้ไข / ถอนคำขอแล้ว) · ขั้นปัจจุบัน · ผู้ส่ง / วันที่ · ผลล่าสุด / วันที่ · จัดการ (`เปิดดู`) · ใหม่สุดก่อน

## แท็บตั้งค่า

- สวิตช์ `ต้องให้ Sales Director ยืนยันก่อนส่งถึง MD` · `มีผลกับคำขอใหม่เท่านั้น` · บรรทัด `ลำดับตอนนี้: …` · บันทึกทันที (Toast)

## รายละเอียดคำขอ (`#request=<id>` · `ui.approvalOpen` · เต็มพื้นที่เนื้อหา)

- ลิงก์ `‹ กลับ` (แท็บเดิม) · หัว: ชื่อรอบ · ป้ายสถานะของรอบ · ป้ายสถานะของคำขอ · มีผลตั้งแต่ · เลขคำขอ · เหตุผลของรอบ · ผู้ส่ง / ข้อความ
- ไทม์ไลน์ขั้นอนุมัติแนวนอน: ทุกขั้นแสดงบทบาท · ชื่อขั้น · สถานะ (รอ · ขั้นปัจจุบัน · ผ่าน · ส่งกลับ · ไม่ใช้ขั้นนี้) · ผู้ทำและวันที่ · ขั้นปัจจุบันเส้นขอบสีหลัก · ขั้นที่ไม่ใช้ = เส้นประจาง (2 ขั้น / 3 ขั้น ตามคำขอ)
- ชุดสรุปตอนส่ง (เลื่อนภายในพื้นที่ · หน้าไม่เลื่อนที่ 1920×1080): ตัวเลขหลัก 4 การ์ด · ตารางราย Channel (+ แถว Total) | หน่วยขายที่เปลี่ยนมากที่สุด · ความครบของแผน SKU (ลิงก์ Plan Summary › ติดตามสถานะ) ·
  ประเภทสินค้าในแผน + Clearance · กราฟรายเดือน (`charts.compareLines` เดียวกับแท็บเปรียบเทียบ · รอบก่อนเส้นประ · เดือนล็อกพื้นเทา · เส้นเดือนที่มีผล · แกน 0)
- ลิงก์ `ดูรายงานเต็ม` (เลือกรอบ → Plan Summary แท็บรายงาน) · `เปรียบเทียบละเอียด` (A = รอบก่อน · B = รอบนี้ → แท็บเปรียบเทียบ · รอบแรกไม่มีลิงก์นี้)
- แถบเตือนสีแดง `ข้อมูลเปลี่ยนหลังส่งขออนุมัติ ({ส่วนที่ต่าง})` เมื่อชุดสรุปที่คำนวณใหม่ต่างจากที่เก็บไว้
- ความคิดเห็น: รายการตามเวลา · ช่องเพิ่มสำหรับผู้มีสิทธิ์แก้ไขหน้า
- แถบคำสั่งท้ายหน้า (อยู่ล่างสุดเสมอ): `sdConfirm` = ยืนยัน · ส่งกลับแก้ไข · `mdLock` = อนุมัติและ Lock (Dialog 2 ชั้น · พิมพ์ชื่อรอบ) · ส่งกลับแก้ไข · ผู้ส่ง (ยังถอนได้) = ถอนคำขอ ·
  ไม่ใช่ผู้ดำเนินการ = `ขั้นปัจจุบัน: … · รอ {บทบาท} ดำเนินการ` · คำขอปิดแล้ว = `คำขอนี้ปิดแล้ว ({สถานะ})` · ส่งกลับต้องมีข้อความ
