# คู่มือการใช้งาน (`modules/about-prototype`, id `aboutPrototype`)

CR-28 แทนหน้าเกี่ยวกับ Prototype (คง id · Path · ลิงก์เดิมใช้ได้) · เมนูกลุ่ม `ช่วยเหลือ` (group id `project-info` เดิม) เห็นทุกบทบาท (`open: true`) ·
ลิงก์ Header `คู่มือ` · fit (เนื้อหาแท็บเลื่อนภายในการ์ด) · ไม่มีปุ่ม `?` ที่หัวหน้านี้
เนื้อหาทั้งหมดอยู่ใน `data/guide.js` (แก้ข้อความ ลำดับงาน สถานการณ์ทดสอบได้โดยไม่แก้โค้ด) · ป้ายบนหน้าจออยู่ใน `pages.aboutPrototype` · ฟังก์ชันล้วนอยู่ใน `core/guide.js`

ตัดออกจากหน้าจอ (CR-28): ขอบเขต · สิ่งที่ตัดออกโดยตั้งใจ · Decision log · คำถามที่ค้าง · ขั้นต่อไป · กล่องสิ่งที่ขออนุมัติ —
อยู่ใน `docs/DECISIONS.md` · `docs/spec/open-items.md` · `docs/spec/business-rules.md` เท่านั้น

## แท็บ (จำที่ `ui.guideTab` · `#uat` / `#uat-S4` = แท็บ UAT + กางการ์ดสถานการณ์นั้น)

### ภาพรวมและลำดับงาน (อ่านจบในจอเดียวที่ 1920×937)

- `ภาพรวม` 1 บรรทัด (`guide.overview`)
- `ลำดับการทำงาน` (`components.flowDiagram` · HTML + SVG):
  - การ์ด 4 ขั้นต่อด้วยลูกศร: เลขขั้น · ชื่อหน้า · Chip ผู้แก้ไข (สีตามลำดับบทบาท `--person-*`) · สิ่งที่ทำ · ผลลัพธ์ · `ไปหน้านี้`
  - ผู้แก้ไขคำนวณจากสิทธิ์จริง (`guide.pageEditors` · ไม่นับบทบาทที่แก้ได้ทุกหน้า · ไม่มีผู้แก้ไข = `ทุกบทบาท`)
  - การ์ดที่บทบาทปัจจุบันเป็นผู้แก้ไข = ไฮไลต์ + ป้าย `บทบาทของคุณ` · หน้าที่บทบาทไม่เห็น = ปุ่มกดไม่ได้ (Tooltip บอกเหตุผล)
  - การ์ดขั้นที่ 3 มีกล่อง `↺ ยังไม่ครบเป้า: …` · แถวล่าง: `ข้อมูลที่ต้องมีก่อน` Product Master · Account Master
    (ผู้ดูแล = รวมผู้แก้ไขของทุกหน้าในกลุ่มเมนู `guide.groupEditors`) + `แก้ไขย้อนกลับได้ทุกขั้น …`
- `บทบาทและหน้าที่` (`guide.roleRows` จากสิทธิ์ปัจจุบันในหน้า Permissions ไม่พิมพ์ซ้ำ · CR-31 แทนหน้า Roles ที่ซ่อน):
  บทบาท (+ Chip `สร้างเอง` · รวมบทบาทที่สร้างเอง) · คำอธิบาย · แก้ไขได้ที่ (ชื่อย่อหน้า · ผู้ดูแลระบบ = `ทุกหน้า ยกเว้น …` · ไม่มี = `ดูอย่างเดียว`) ·
  หน้าเริ่มต้น · จำนวนผู้ใช้ (`{n} คน` นับผู้ใช้ที่มีบทบาทนั้น) · แถวบทบาทปัจจุบันไฮไลต์
- `สำหรับการทดสอบ` (`guide.testNotes` · วันที่ข้อมูลจาก `core/clock.js`) · CR-31: บรรทัด `สิทธิ์ใน Prototype ใช้ซ่อนเมนูและปุ่มบนหน้าจอเท่านั้น ระบบจริงต้องตรวจสิทธิ์ที่ Backend`
  (แสดงที่นี่ที่เดียวในระบบ · หน้า Role Management ไม่มีข้อความนี้แล้ว)

### คำศัพท์และสูตร

- คำศัพท์ 10 คำ (`guide.glossary`) · `{gpLabels}` / `{unitLabels}` / `{range}` เติมจาก Channel Master และ `clock` (ไม่พิมพ์ชื่อเอง)
- สูตร (`guide.formulaLines`): `Sale Amount = …` + 1 บรรทัดต่อ Channel ที่ใช้งาน · มีส่วนแบ่ง = `÷ 1.07 × (1 − {gpLabel})` · ไม่มี = `÷ 1.07`
- ความหมายสีคงเหลือ 4 Chip (`alert-ok / short / over / empty`)

### สถานการณ์ทดสอบ (UAT)

- ด้านบน: `ชื่อผู้ทดสอบ` · `วันที่ทดสอบ` (ค่าเริ่มต้นวันนี้) · `ทดสอบแล้ว x/10 · ผ่าน a · ไม่ผ่าน b` · `ส่งออก ▾` (Excel / CSV · ทุกบทบาทส่งออกได้ แม้ไม่มีสิทธิ์ส่งออกแผน) ·
  `ล้างผลการทดสอบ` (กล่องยืนยัน) + ข้อความเตือน `ผลการทดสอบเก็บในเบราว์เซอร์นี้เท่านั้น …`
- การ์ดพับได้ 10 ใบ (`guide.scenarios` · CR-29 S7 = สิ้นสุดการรับผิดชอบของ Sales Officer TT เขต 4 แล้วให้คนใหม่รับช่วง ที่หน้า Sales Person Management ·
  CR-32 S10 = เปลี่ยนผู้รับผิดชอบ EVEANDBOY เป็นอนันต์ตั้งแต่ มิ.ย. 2027 แบบแทนที่ช่วงที่เหลือ → อนันต์ มิ.ย.–ธ.ค. 2027 · ข้อมูลที่ต้องตรวจไม่เพิ่ม · มุมมองตามบุคคลมีเป้า EVEANDBOY ตั้งแต่ มิ.ย.): หัว = รหัส · ชื่อ · Chip บทบาท (+ Channel) · `กำลังทดสอบ` · ขั้นที่ทำ x/y · ผล
  - `เริ่มสถานการณ์นี้` (`guide.uatStart`): `ui.role` = ผู้ใช้ของสถานการณ์ · `ui.selection` (ถ้ากำหนด) · `uat.results.active` · Toast · เปิดหน้าแรกในแท็บเดิม
  - ขั้นตอน + Checkbox `ทำแล้ว` · ผลที่คาดหวัง (กล่องจาง) · ผล `ผ่าน` · `ไม่ผ่าน` · `ข้าม` + `หมายเหตุ / ปัญหาที่พบ`
    (`ไม่ผ่าน` ต้องมีหมายเหตุ ไม่อย่างนั้นบันทึกไม่ได้และแสดงข้อความ) · บันทึกผลของสถานการณ์ที่กำลังทดสอบ = จบ (แถบลอยหาย)
- แถบลอยมุมล่างขวาทุกหน้ายกเว้นคู่มือ (`core/layout.js`): `กำลังทดสอบ S4 · ขั้นที่ 2/4` (ขั้นแรกที่ยังไม่ติ๊ก) + `กลับไปบันทึกผล` ·
  อยู่เหนือแถบก่อนหน้า/ถัดไป · ไม่พิมพ์
- ผลเก็บที่ `uat.results` · `รีเซ็ตข้อมูล` ไม่ล้าง (`layout.resetData` คง Key `uat.*`)
- ส่งออก `UAT-Results_{YYYYMMDD}`: 1 แถวต่อสถานการณ์ = ผู้ทดสอบ · วันที่ · รหัส · สถานการณ์ · บทบาท · ขั้นตอนที่ทำ (x/y) · ผล · หมายเหตุ +
  แถวหัวไฟล์ ผู้ทดสอบ · วันที่ทดสอบ · ความคืบหน้า

## ปุ่ม `?` ที่หัวทุกหน้า (`components.pageHelp` · ใส่โดย `core/layout.js`)

- ต่อท้ายชื่อหน้าทุกหน้าในเมนู (ยกเว้นคู่มือ) · หน้าไม่มี `guide.pages.<id>` = ไม่มีปุ่ม
- Popover: `หน้านี้ใช้ทำอะไร` · `ผู้แก้ไข` (`guide.pageEditors` · ไม่มี = `ทุกบทบาทดูได้อย่างเดียว`) · `ขั้นตอนหลัก` ≤ 3 ข้อ · `ดูคู่มือทั้งหมด`
- Module เพิ่มหัวข้อได้ด้วย `ctx.addHelp(label, build)` (กดแล้วแสดงในกล่องเดิม + `← กลับ`) —
  SKU Planning: `กฎ Status และวิธีเติมยอด` (Legend + กฎ + คีย์ลัด · แทนปุ่ม `?` เดิมในแถวเครื่องมือ)
