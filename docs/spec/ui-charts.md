# มาตรฐานกราฟ (`core/charts.js` SVG/CSS เขียนเอง)

แยกจาก [ui-standards.md](ui-standards.md) (CR-34 · ไฟล์เกิน 30 KB) · สไตล์ที่ `styles/components.css` ส่วน "กราฟ" · สีเป็น Token ใน `styles/tokens.css`

- **แท่งเป้าหมายเทียบ L12M** (หน้า Annual Target · Sub-channel Allocation และตารางรายงาน)
  - สเกลจริงเดียวกันทั้งตาราง เริ่มที่ 0 ห้ามสเกลต่อแถว
  - ค่าสูงสุดของสเกลปัดขึ้นขั้นละ 10 ล้าน (ถ้าค่าสูงสุด < 30 ล้าน ขั้นละ 5 ล้าน)
  - แท่ง = เป้าหมาย · ขีดตั้ง = ยอดขาย L12M · ไม่มียอดขาย L12M = ป้าย `ใหม่`
  - แกน `0 · 20 · 40 · 60 ล้าน` ใต้ชื่อคอลัมน์ · สีตาม Channel
  - CR-27 ใช้ `charts.vsLastYearBar` กับ `เป้าหมายเทียบแผน` รายผู้รับผิดชอบด้วย: ขีด = แผน · สีตามสถานะคงเหลือ · `opts.title` แทน Tooltip · `opts.newTag: false` ไม่มีป้าย `ใหม่`
- **การเติบโตติดลบ** (CR-27 `components.targetGrowth`): ตัวเลขการเติบโต + `▼` เล็ก (`.growth-warn`) + Tooltip `เป้าหมายต่ำกว่ายอดขาย 12 เดือนล่าสุด` · ไม่บล็อกการบันทึก
- **กราฟรายเดือน** (เป้าหมาย / แผน / ยอดขายอ้างอิง · `charts.barLine` · CR-34 รายงานสรุปแผนเปลี่ยนเป็น `planTargetBars` ด้านล่าง)
  - เป้าหมาย = แท่งสีหลักอ่อน · แผน = เส้นทึบ 3px มีจุด · ยอดขายอ้างอิง = เส้นประ 1.5px
  - แกน Y เริ่ม 0 ค่าสูงสุด × 1.10 ปัดเป็นเลขกลม เส้นแบ่ง 4–6 เส้น ขั้นละ 1 / 2 / 2.5 / 5 × 10^n
  - ป้ายท้ายเส้นที่ ธ.ค. · Legend ใช้สัญลักษณ์เดียวกับที่วาด
- **Waterfall** ที่มาของการเติบโต
  - แนวนอน · เพิ่ม เขียว · ลด แดง
  - แกนเริ่มที่เลขกลม: ค่าต่ำสุด ≥ 200 ล้าน ขั้นละ 100 ล้าน · ≥ 50 ล้าน ขั้นละ 50 ล้าน · ต่ำกว่านั้นเริ่มที่ 0
  - แกนไม่เริ่มที่ 0 = สัญลักษณ์ตัดแกน + `แกนเริ่มที่ 100 ล้านบาท`
  - เริ่มจาก `ยอดขาย L12M` (CR-24) · ใช้ในรายงานสรุปแผนและหน้า Annual Target
  - CR-27 รายงานสรุปแผน: การ์ดคู่ 55 : 45 (Waterfall | แท่งสัดส่วน Channel 100% แถว L12M · ปีแผน) · กราฟชิดบนของการ์ด
- **แท่งแนวตั้งซ้อน** `charts.stackedColumns` (CR-24 · หน้า Annual Target): แท่งละปี ซ้อนตาม Channel · แท่งเป้าหมายขอบเน้น ·
  ตัวเลขรวมเหนือแท่ง · การเติบโตระหว่างแท่ง (CR-27 callback คืน `{ text, muted }` ได้ = ข้อความจาง เช่น `ช่วงเวลาทับซ้อน` ระหว่าง 2025 กับ L12M) · % ในช่วงเมื่อสูง ≥ 14px · แกน Y เริ่ม 0 เผื่อ 10% (ป้ายแกนเว้นช่องเมื่อห่างกัน < 16px) ·
  `onHover` / `.highlight(id)` ใช้ไฮไลต์ร่วมกับตาราง · สไตล์ `.scol-*` อยู่ใน `modules/top-down/top-down.css`
- **ตาราง Pivot สีพื้นไล่ความเข้ม** (CR-26 รายงานสรุปแผน): สีหลักผสมพื้นขาว 0–45% ตามค่า ÷ ค่าสูงสุดของระดับแถวเดียวกัน · Legend น้อย → มาก · ช่อง 0 ว่าง
- **แท่งซ้อน 100%** `charts.stackedShare`: ป้าย % ในช่วง (CR-27 `part.text` แทนป้ายได้ เช่น `{ล้านบาท} · {%}` · `minLabel` = ช่วงแคบสุดที่มีป้าย) · ใช้กับสัดส่วน Channel (CR-34 ตัดแท่ง Status ของแผนออก)
- **ป้าย `ประมาณการ` ที่หัวคอลัมน์เดือน** (CR-27 SKU Planning แทนจุดกลวงรายช่องของ CR-24): 1 ป้ายต่อเดือนที่มี SKU ใช้ยอดอ้างอิงประมาณการ + Tooltip จำนวน SKU
- **แผนภาพลำดับงาน** (CR-28 `components.flowDiagram` หน้าคู่มือ): การ์ดขั้น + ลูกศร SVG · Chip บทบาท (`.role-chip` สี `--person-*` ตามลำดับบทบาท) ·
  การ์ดของบทบาทปัจจุบันไฮไลต์ + `บทบาทของคุณ` · หน้าที่ไม่เห็น = ปุ่มกดไม่ได้ · กล่อง `↺` วนกลับ · แถวข้อมูลที่ต้องมีก่อน
- **แท็บตัวกรองพร้อมจำนวน** (CR-28 ติดตามสถานะ): `segmented` ป้าย `{ชื่อ} ({n})` · จำนวน 0 = สีจาง (`option.className` `is-zero`) แทน Checkbox
- **แถบลอยระหว่างทดสอบ** (CR-28 `.uat-bar`): มุมล่างขวา เหนือแถบก่อนหน้า/ถัดไป · ไม่พิมพ์
- **ข้อมูลที่ต้องตรวจ มาตรฐานใหม่** (CR-32 `components.dataCheck` · ใช้ใน Account Master และ Sales Person Management ก่อน): Chip เหลือง `ข้อมูลที่ต้องตรวจ (n)` / เทา `ข้อมูลครบ` ·
  Popover จัดกลุ่ม `<เกณฑ์> (n)` · ปุ่ม `ไปที่รายการ` (เลือกแท็บ · กรอง · เลื่อน · ไฮไลต์แถว 2 วินาที `components.flashRow`) · ท้าย `เกณฑ์ที่ตรวจ:` (แสดงแม้ n = 0) · หน้าอื่นยังใช้ `checksChip`
- **Account Master** (CR-29): Chip `ข้อมูลที่ต้องตรวจ (n)` (`components.checksChip` · มีรายการ = สีเตือน · 0 = สีจาง) · Drawer ขวาแท็บ `ข้อมูล | ประวัติการเปลี่ยนแปลง`
  (`components.historyList`) · ชื่อคน = ลิงก์ขีดเส้นใต้จางไป Drawer ของคน (`components.personLink`) · ผู้รับผิดชอบ n เดือน (`components.ownerTimeline` แถบสีตามคน ·
  ว่าง = ลายเส้นแดงจาง · สิ้นสุดแล้ว = สีเตือน) · Chip ทีม `{Channel} · {บทบาท}` ขอบสี Channel · ไอคอน 👥 = บุคลากรประเภททีม
- **CR-36 Waterfall แนวตั้ง** `charts.waterfallColumns` (Annual Target · ฟังก์ชันใหม่ ไม่แก้ `waterfall` แนวนอนของรายงาน): แกน Y เริ่มเลขกลม + ตัดแกน · แท่งเทาเริ่มฐาน · ส่วนต่างลอย ·
  เส้นประยอดสะสม · ค่าบนแท่ง · เต็มพื้นที่ผู้วาง · `.info` / `.update` / `.highlight` เหมือน `waterfall`
- **CR-36 ลายจุด** `dots: true` ของ stack / part ใน `planTargetBars` · `partBars` = แผน Clearance (ไม่นับในเป้าหมาย · Token `--c-type-clearance-plan`)
- **CR-34 แผนซ้อนตามประเภท** `charts.planTargetBars` (รายงานสรุปแผน · เป้าหมายเทียบแผนรายเดือน): แท่งซ้อนล่าง → บน สินค้าเดิม · NPD ยืนยันแล้ว · ขอ NPD (ลายเส้น) · Clearance (เทา ·
  Legend เฉพาะเมื่อมี) · ส่วนที่เป็น 0 ไม่วาด · ขีดเป้าหมายหนา 3px สีเข้ม (`--chart-target-tick`) กว้างกว่าแท่งข้างละ 6px ไม่เชื่อมระหว่างเดือน ·
  เส้นประยอดขายอ้างอิงกด Legend ซ่อน / แสดง (ค่าเริ่มต้นแสดง) · แกน Y เริ่ม 0 จากค่ามากสุดของแท่ง เป้าหมาย ยอดอ้างอิง · แถว `ส่วนต่าง` ใต้ชื่อเดือน สีตามคงเหลือ
  (`ครบ` เมื่อ |ส่วนต่าง| < 0.05 ล้าน · `calc.planDiff`) · ไม่มีป้ายท้ายเส้น (สรุปทั้งปีอยู่หัวกราฟ)
- **CR-34 แท่งแนวนอนซ้อน** `charts.partBars` (สัดส่วนแผนตามประเภท / ตามกลุ่มสินค้า): สเกลจริงเริ่ม 0 ค่าสูงสุดเดียวกันทุกแถว · ค่า > 0 กว้างอย่างน้อย 4px · ตัวเลขท้ายแท่งเสมอ ·
  บรรทัดเล็กใต้ชื่อ (`sub`) · ข้อความเตือนสีแดง (`note`) · สีและลายของประเภทจาก `labels.planTypes` (`token` · `borderToken` · `pattern: 'hatch'`)
- **อื่นๆ**: แท่งซ้อนตามหน่วยขาย (มุมมองรวมของ Sub-channel Allocation) · แท่งแนวนอน `hbars` · แถบแบ่งเงิน Net Sales / GP / VAT
- ห้าม Donut · ค่าคงที่ของแกนอยู่ใน `settings.CHART_*` · `AXIS_START_RULES` · `SCALE_STEP_*`
