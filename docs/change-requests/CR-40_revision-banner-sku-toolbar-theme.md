## 1. แถบสถานะ Revision

### 1.1 โหมดดู

- **ไม่มีแถบสถานะ**
- ป้ายข้างชื่อรอบที่หัวหน้า (`2027 · R1 [ร่าง] ▾`) เป็นตัวบอกสถานะ ใช้สีตามข้อ 3.3
- Hover ป้ายแล้วแสดง Tooltip

| สถานะ | Tooltip |
|---|---|
| ร่าง | `แก้ไขได้ตั้งแต่ <เดือนที่มีผล> · เดือนก่อนหน้าใช้ค่าจาก <รอบก่อน>` (R1: `แก้ไขได้ทุกเดือน`) |
| รออนุมัติ | `ส่งขออนุมัติเมื่อ <วันที่> · ขั้นปัจจุบัน <ขั้น>` |
| Lock แล้ว | `Lock เมื่อ <วันที่> โดย <ชื่อ>` |

- รอบที่ไม่ใช่รอบปัจจุบัน: ข้างป้ายมีลิงก์ข้อความเล็ก `ไปรอบปัจจุบัน`
- รอบ `รออนุมัติ` และ `Lock แล้ว` ไม่มีปุ่ม `แก้ไข` อยู่แล้ว (CR-38) จึงไม่ต้องมีแถบบอกว่าอ่านอย่างเดียว

### 1.2 โหมดแก้ไข

- รวมข้อความ Revision เข้ากับแถบโหมดแก้ไขเดิม เป็นแถบเดียว 1 บรรทัด

```
โหมดแก้ไข · 2027 R2 ร่าง · แก้ไขได้ตั้งแต่ เม.ย. 2027 · มีรายการที่ยังไม่บันทึก 2 รายการ
```

- R1: `โหมดแก้ไข · 2027 R1 ร่าง · แก้ไขได้ทุกเดือน · ยังไม่มีรายการที่เปลี่ยนแปลง`
- ใช้กับทุกหน้าใน Sales Planning

### 1.3 แก้ปัญหาตัวอักษรถูกบีบ

- ลิงก์ `3 หน่วยขาย` ใต้ชื่อ Channel ใน Annual Target ถูกบีบเพราะความสูงที่เหลือลดลง
- กำหนดความสูงขั้นต่ำของแถว Channel ให้พอสำหรับ 2 บรรทัดเสมอ
- ห้ามบีบ `line-height` เพื่อให้ไม่ต้องเลื่อนหน้า ถ้าความสูงไม่พอ ให้ลดความสูงของการ์ดกราฟแทน

## 2. SKU Planning: แถวเครื่องมือ

### 2.1 โครงใหม่ (1 แถว)

```
[ค้นหา SKU / ชื่อ]  จัดกลุ่ม [Series|ประเภท|ไม่จัดกลุ่ม]  มุมมอง [จำนวนชิ้น|Sale Amount|Net Sales]  [ตัวกรอง (2)]  [แสดงผล ▾]      [ข้อมูลครบ]
```

**ตัวกรองหลักที่แสดงตลอด**
- ค้นหา
- จัดกลุ่ม
- มุมมอง

**ปุ่ม `ตัวกรอง (n)`**
- n = จำนวนตัวกรองที่ใช้อยู่ · ปุ่มเป็นสีหลักเมื่อ n > 0
- คลิกเพื่อกางแผงตัวกรองในหน้า ใต้แถวเครื่องมือ (ตามมาตรฐาน `ตัวกรองเพิ่มเติม`)
- แผงประกอบด้วย:
  - Series
  - หมวดสินค้า (แบบลำดับชั้น `-` / `--` ตาม CR-36)
  - อายุ
  - ประเภทสินค้าในแผน
  - ประเภทสินค้า (เดี่ยว / Bundle)
  - ช่องติ๊ก `เฉพาะที่ไม่มียอด ≥ 3 เดือน`
- ปุ่มท้ายแผง `ล้างตัวกรอง`

**ปุ่ม `แสดงผล ▾`** เป็นเมนูแบบเลื่อนลง ประกอบด้วย
- `เรียง` (ตัวเลือกเดิม)
- `แสดงยอดอ้างอิง` (สวิตช์)
- `พับทั้งหมด / กางทั้งหมด`
- คำอธิบายสี (เนื้อหาเดิมของปุ่ม ⓘ)

**Chip ข้อมูลที่ต้องตรวจ**
- `ข้อมูลครบ` / `ข้อมูลที่ต้องตรวจ (n)` อยู่ขวาสุดของแถวเดียวกัน
- ห้ามขึ้นบรรทัดใหม่

### 2.2 Chip ตัวกรองที่ใช้

- เมื่อมีตัวกรองและแผงปิดอยู่ ให้แสดงแถว Chip เล็กใต้แถวเครื่องมือ (เช่น `Series: Charming Lab ×` · `อายุ: ≤ 1 ปี ×`) และมีลิงก์ `ล้างทั้งหมด` ท้ายแถว
- ไม่มีตัวกรอง = ไม่มีแถวนี้

### 2.3 แถวแรก

- แถวเลือก Channel / Account และข้อมูลหน่วยขาย (ผู้รับผิดชอบ · GP · เป้าหมายทั้งปี · L12M · การเติบโต) คงเดิม
- แถวคำสั่งในโหมดแก้ไข (`ปรับทั้งหน่วยขาย ±%` · `ปรับให้ครบตามเป้าหมาย` · `+ เพิ่มสินค้าในแผน`) อยู่ในแถบโหมดแก้ไขด้านขวา ไม่เพิ่มแถว

### 2.4 การจำค่า

- ค่าตัวกรอง มุมมอง และการแสดงผล จำต่อผู้ใช้ใน Session เหมือนเดิม

| `--primary-hover` | `#C2185B` | |

- ค่าสีอ้างอิงจากภาพระบบ KOL Management ถ้า Repo ของ KOL Management เข้าถึงได้ ให้ใช้ค่าจริงจาก Repo นั้นแทน และรายงานค่าที่ใช้

### 3.2 โครงหน้า

**แถบบน (Top bar)**
- **ซ้าย:** ช่องค้นหาเมนู `ค้นหาหรือไปที่หน้า…` (กรองรายการเมนูและพาไปหน้า) · ป้าย `Prototype`
- **ขวา:**
  - ตัวเลือก `มุมมองผู้ใช้` แสดงเป็น Avatar วงกลมตัวอักษรแรกของชื่อ + ชื่อ + บทบาท 2 บรรทัด (เลือกได้เหมือนเดิม)
  - ลิงก์ `คู่มือ`
  - เมนู `รีเซ็ตข้อมูล ▾`

**เมนูข้าง**
- **บนสุด:**
  - กล่องโลโก้ (ไอคอนแอป + `Sales Target Planning` / `Charmiss` 2 บรรทัด)
  - ปุ่มพับเมนูแบบไอคอนที่มุมขวาของกล่อง (แทนปุ่ม `« พับเมนู` ด้านล่าง)
- **หัวกลุ่มเมนู:** ตัวพิมพ์ใหญ่ ตัวเล็ก สี `--text-muted`
- **รายการเมนู:**
  - ไอคอน + ชื่อ
  - รายการที่เลือกใช้พื้น `--primary-soft` ตัวอักษรและไอคอน `--primary`
- **ล่างสุด:** `v<เวอร์ชัน> · Prototype` ตัวเล็ก
- เมนูพับแล้วแสดงเฉพาะไอคอน และ Tooltip ชื่อหน้า

**หัวหน้า (Page header)**
- การ์ดพื้น `--header-gradient` มุมโค้ง `--radius-card` ความสูงไม่เกิน 88px
- **บรรทัดแรก:** Breadcrumb `<Module> › <หน้า>` ตัวเล็ก
- **บรรทัดที่สอง:**
  - ชื่อหน้า (ตัวหนา) · ปุ่ม `?` · ตัวเลือกปี / Revision และ `ข้อมูล ณ เดือน` ถ้ามี
  - ปุ่ม `ส่งออก` · `แก้ไข` / `บันทึก` · `ยกเลิก` ชิดขวาในแถบเดียวกัน
- ข้อความ `ดูอย่างเดียว · แก้ไขได้โดย …` อยู่ซ้ายของปุ่มในแถบเดียวกัน
- **ตัดคำอธิบายใต้หัวข้อของทุกหน้า** ย้ายข้อความไปเป็นบรรทัดแรกในปุ่ม `?` (ทำแล้วใน Product Master)

**แท็บ**
- แบบขีดเส้นใต้: ข้อความ `--text-muted` · แท็บที่เลือกใช้ `--primary` และเส้นใต้ 2px
- ตัวนับในแท็บเป็นตัวเลขเล็กสีเทาต่อท้าย เช่น `ทั้งหมด 5`
- ใช้กับแท็บระดับหน้าทุกหน้า
- ปุ่มสลับค่า (เช่น `จำนวนชิ้น | Sale Amount | Net Sales`) ยังเป็นปุ่มกลุ่ม แต่ใช้สี Token ใหม่

**การ์ดและตาราง**
- **การ์ด:** พื้น `--surface` · ขอบ `--border` · มุม `--radius-card` · เงา `--shadow-card`
- **หัวตาราง:** พื้นขาว ตัวอักษร `--text-muted` ตัวหนา และเส้นใต้หัวตาราง
- **แถว:** เส้นคั่นบาง `--border` · Hover พื้น `#FBF8FA`

**ปุ่ม**
- **ปุ่มหลัก:** พื้น `--primary` ตัวอักษรขาว มุม `--radius-control`
- **ปุ่มรอง:** พื้นขาว ขอบ `--border`
- **ปุ่มข้อความ:** สี `--primary`

### 3.3 ป้ายสถานะ

- ทุกป้ายเป็นรูป Pill พื้นสีอ่อน ตัวอักษรสีเข้มของกลุ่มเดียวกัน ไม่มีเส้นขอบ

| กลุ่ม | ป้าย |

| warning | รออนุมัติ · เกิน · จะสิ้นสุด · ข้อมูลที่ต้องตรวจ · ขาดที่ควรมี |

| neutral | ร่าง · ปิดใช้งาน · ยังไม่กำหนด · Discontinued · สิ้นสุด |

- แถวคงเหลือท้ายกลุ่มใช้สีพื้นจาก `*-soft` ตามมาตรฐานเดิม

## 5. Test (`node tests/run.js`)

**สี**
- ไม่มีค่าสีฐานสิบหก (`#xxxxxx`) หรือ `rgb(` ในไฟล์หน้า (`pages/`) และ Component ยกเว้นไฟล์ Token กลางและไฟล์สีกราฟ

**ไอคอนเมนู**
- ทุกรายการเมนูมีชื่อไอคอนที่อยู่ใน `assets/icons.js`
- ไม่มีตัวอักษรเดี่ยวในกรอบเหลืออยู่

**คำอธิบายใต้หัวข้อ**
- ไม่มีหน้าใดเรียก Component คำอธิบายใต้หัวข้อ
- ข้อความเดิมทุกหน้าอยู่ในเนื้อหาปุ่ม `?`

**แถบสถานะ Revision**
- โหมดดูไม่มีแถบ
- โหมดแก้ไขมีแถบเดียว

**SKU Planning**
- ตัวนับในปุ่ม `ตัวกรอง (n)` ตรงกับจำนวน Chip
- `ล้างตัวกรอง` ทำให้ n = 0

**ตัวเลขเดิม**
- ตัวเลขทุกหน้าเท่ากับก่อนทำ CR (CR นี้แก้เฉพาะการแสดงผล)
